# 拖车杠

## 概述

利用 V80 大梁尾部预埋螺栓孔安装 2" 方口拖车杠（receiver hitch），作为车尾储物箱和自行车架的标准化安装接口。不用于拖挂。

## 规格

| 项目 | 参数 |
|------|------|
| 方口规格 | 2" receiver（约 50×50 mm 内孔） |
| 安装位 | 原车大梁尾部预埋螺栓孔（左右各 ≥4 颗） |
| 材质 | 钢制，防锈喷涂 |
| 额定载荷 | ≥150 kg 垂向（实际挂载控制在 100 kg 以内） |

## 安装要点

1. 确认大梁预埋孔位无锈蚀、螺纹完好
2. 拖车杠与车架之间加橡胶垫片防异响
3. 螺栓打扭矩至厂家推荐值，加螺纹胶防松
4. 方口中心对中车身，左右偏差 ≤5mm
5. 安装后喷黑色底盘装甲漆覆盖螺栓头，防锈

## 年审

拖车杠本体固定在大梁下方，位置隐蔽。不挂载时方口不外凸，不影响年审。如需拆除，松 8 颗螺栓即可取下。

## 跨模块依赖
