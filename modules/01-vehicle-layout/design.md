# 设计决策：整车布局

## 📋 需求前提

- **乘员/铺位**：2 大 1 小露营，偶尔长途。
- **必备功能**：淋浴、简易马桶、水槽、收纳、操作台面。
- **车型**：上汽大通 V80（长轴），内宽约 1.7–1.8m。
- **原则**：模块化、可拆检、年审可恢复空车（呼应 build-guide 的螺栓锚固思路）。

## 🧭 朝向与坐标（关键基准）

- **滑门在右**（副驾侧）。做饭、洗漱开门朝外，油烟湿气外排。
- 约定视角：**前=车头方向，左=驾驶侧墙，右=滑门侧墙**。
- 横向内宽按 ~175cm 排布：左墙 → 床基座 → 中央过道 → 右侧柜排 → 右墙。

## 🗺️ 总体布局（三体块）

```
前｜驾驶舱
──────────────┬──────────────
 冰箱位(二排前)│              │
 兼小孩脚踏    │ 台面段(高70+) │  ← 右排·近中门：水槽/电磁炉
──────────────┼──────────────
 二排座椅(固定)│              │
──────────────┼──────────────
 ┌─衣帽区───┐ │              │
 │抽屉(上部) │ │  中央过道     │  → 通尾门
 │行李箱(底) │ │              │
 └──────────┘ │              │
──────────────┤ 床段(=基座高) │  ← 右排·近尾门：夜间床右半张
   床固定基座  │              │
   (靠左墙)    │              │
──────────────┴──────────────
后｜尾门
```

三个独立体块，各自箱体、螺栓压在地台预埋点上，可单独拆走。

### 1. 后横床（左侧基座 + 向右抽拉）
- **固定基座**靠左墙，夜间**向右抽拉盖住中央过道**，抽出段落在右排"床段"柜顶上，连成整张床。
- 因此**右排尾段柜顶必须与床基座同高**，否则拼不平。
- 铺位净尺寸（长/宽）**待现场按实车核实**——空车内宽横躺偏短，可能需侧壁做凹槽借长。

### 2. 中段衣帽区（床与二排座椅之间，靠左）
- 原湿区位置改建：利用既有铝型材框架分格，**底部行李箱竖放 + 上部抽屉/搁板**。
- 底部箱格：内空高 **≥75cm**（28 寸箱带轮 ≈73cm），箱门朝过道开，站在过道即可翻箱。
- 上部：1~2 层抽屉/搁板放每日内衣袜子等小件；宽度按箱数分配（2 箱并排 ≈90cm，或 1 箱 + 抽屉柱）。
- 详见 [07-cabinetry](../07-cabinetry/design-wardrobe.md)。
- ⚠ 原帘式湿区已迁出此位，**淋浴新位置待定**（见 [09-shower-module](../09-shower-module/)）。

### 3. 二排前冰箱位（兼小孩脚踏）
- 二排座椅**固定不旋转**，前方空间驻车时闲置 → 放上开门卧式冰箱（型材框架箱体）。
- 箱体顶面 = 可掀软垫盖板，**兼作安全座椅小孩的脚踏**（脱鞋踩），位置按安全座椅实际安装位对齐。
- 碰撞安全：箱体必须 **M8 螺栓压地台预埋点**——满载 ~20kg，追尾时是抛射物不是固定件。
- 详见 [07-cabinetry](../07-cabinetry/design-fridge-bay.md)。

### 4. 右侧阶梯柜排（中门→尾门一整排）
一整排柜子，深度/高度随功能分段变化：

| 分段 | 位置 | 柜顶高度 | 深度 | 用途 |
|------|------|----------|------|------|
| 台面段 | 近中门 | **70+ cm**（站着操作舒适） | ~40–45cm | 水槽 + 电磁炉 + 下方储物 |
| 床段 | 近尾门 | **= 床基座高**（夜间承床） | 视床宽 | 夜间床的右半张 + 白天储物 |

- 台面段与床段前后错开：台面在中门、床段在尾门，**互不打架**。
- 台面段深度压在 **~40cm 以内**，避免夜间床抽出时相撞。
- 柜排**不得挡住滑门有效开口**（V80 门洞约 1m，逃生 + 搬运通道），台面/柜体在门洞前后错开落位。

## 🔄 白天 / 夜间转换

**白天**：中央过道贯通至尾门；台面段做饭；餐桌方案待定（二排不旋转，中段已改衣帽区）。
**夜间**：床向右抽拉盖过道 → 与右排床段柜顶拼成整张后横床。

## 📐 关键尺寸（待实车核实，先记占位）

| 项 | 暂定值 | 说明 |
|----|--------|------|
| 内宽排布 | 左墙+床基座+过道+柜排+右墙 ≈ 175 | 床段柜与床基座等高 |
| 衣帽区 | 70 深 × 100 宽，箱格内空高 ≥75 | 28 寸箱竖放 + 上部抽屉 |
| 冰箱位 | 卧式箱高 35~45，顶面 ≈45 兼脚踏 | 高度按孩子腿长试坐定 |
| 台面段柜顶 | 70+ cm | 站立操作高度 |
| 床段柜顶 | = 床基座高 | 需与基座齐平 |
| 台面段深度 | ≤ 40cm | 防止撞抽拉床 |

## 🧩 可拆 / 年审恢复

- 三体块均为独立箱体，角码 + 螺栓压地台预埋点（M8 爬地螺母 / L-track）。
- 冰箱位、衣帽区同为型材框架 + 螺栓固定，随体块一并可拆。
- 湿区（原方案）：地漏软管**快接**、进水**快接**、便携马桶不接管、浴帘可摘 → 整柱可抬走。新位置确定后沿用同原则。
- 台面：进出水快接 → 柜体可整体拆。
- 年审松螺栓、断快接，恢复空车。

## 💨 通风（不动车顶）

- 淋浴位置待定，排风方案随最终位置再定（原则不变：蒸汽强排，就近开侧窗/侧壁百叶）。
- 冰箱位：顶面被脚踏占用，散热走箱体侧面——两侧留通风槽。

3. 台面段相对滑门门洞的**精确落位**（确保不挡开口）。
