# 设计决策：整车布局

## 📋 需求前提

- **乘员/铺位**：2 大 1 小露营，偶尔长途。
- **必备功能**：淋浴、简易马桶、水槽、收纳、操作台面。
- **车型**：上汽大通 V80（长轴），内宽约 1.7–1.8m。
- **原则**：模块化、可拆检、年审可恢复空车（呼应 build-guide 的螺栓锚固思路）。

## 🧭 朝向与坐标（关键基准）

- **滑门在右**（副驾侧）。做饭、洗漱开门朝外，油烟湿气外排。
- 约定视角：**前=车头方向，左=驾驶侧墙，右=滑门侧墙**。
- 横向内宽按 ~175cm 排布：左墙 → 床基座 → 中央过道 → 右侧柜排 → 右墙。

## 🗺️ 总体布局（三体块）

```
前｜二排座椅（旋转当餐椅）
──────────────┬──────────────
              │ 台面段(高70+) │  ← 右排·近中门：水槽/电磁炉
 ┌─帘─────帘─┐ │              │
 │ 湿区帘柱   │ ├──────────────
 │ 盘70×100  │ │              │
 │ 站立70×60 │ │  中央过道     │  → 通尾门
 └─倒角──────┘ │              │
──────────────┤ 床段(=基座高) │  ← 右排·近尾门：夜间床右半张
   床固定基座  │              │
   (靠左墙)    │              │
──────────────┴──────────────
后｜尾门
```

三个独立体块，各自箱体、螺栓压在地台预埋点上，可单独拆走。

### 1. 后横床（左侧基座 + 向右抽拉）
- **固定基座**靠左墙，夜间**向右抽拉盖住中央过道**，抽出段落在右排"床段"柜顶上，连成整张床。
- 因此**右排尾段柜顶必须与床基座同高**，否则拼不平。
- 铺位净尺寸（长/宽）**待现场按实车核实**——空车内宽横躺偏短，可能需侧壁做凹槽借长。

### 2. 帘式湿区（居中·全高帘柱）
- 位于**二排座椅与床基座之间**的中段空间。
- **落地到顶**，站立淋浴（层高够用，不开顶排风扇但净高照用）。
- **防水盘 70深 × 100宽**（低处放大、好糊 GRP、不易渗）；**站立净空 70×60**（够洗澡，让位旁边台面）。
- 朝过道的角**切倒角**（模型里那个斜面），通行不磕、进出顺。
- 两面贴墙/贴柜做防溅硬壁板，另两面走配重浴帘；不用时帘子归拢，湿区还原成过道。

### 3. 右侧阶梯柜排（中门→尾门一整排）
一整排柜子，深度/高度随功能分段变化：

| 分段 | 位置 | 柜顶高度 | 深度 | 用途 |
|------|------|----------|------|------|
| 台面段 | 近中门 | **70+ cm**（站着操作舒适） | ~40–45cm | 水槽 + 电磁炉 + 下方储物 |
| 床段 | 近尾门 | **= 床基座高**（夜间承床） | 视床宽 | 夜间床的右半张 + 白天储物 |

- 台面段与床段前后错开：台面在中门、床段在尾门，**互不打架**。
- 台面段深度压在 **~40cm 以内**，避免夜间床抽出时相撞。
- 柜排**不得挡住滑门有效开口**（V80 门洞约 1m，逃生 + 搬运通道），台面/柜体在门洞前后错开落位。

## 🔄 白天 / 夜间转换

**白天**：中央过道贯通至尾门；湿区帘归拢作过道；台面段做饭；二排旋转椅当餐椅。
**夜间**：床向右抽拉盖过道 → 与右排床段柜顶拼成整张后横床；湿区洗后刮干、帘归拢。

## 📐 关键尺寸（待实车核实，先记占位）

| 项 | 暂定值 | 说明 |
|----|--------|------|
| 内宽排布 | 左墙+床基座+过道+柜排+右墙 ≈ 175 | 床段柜与床基座等高 |
| 湿区防水盘 | 70深 × 100宽 | 站立净空 70×60 |
| 台面段柜顶 | 70+ cm | 站立操作高度 |
| 床段柜顶 | = 床基座高 | 需与基座齐平 |
| 台面段深度 | ≤ 40cm | 防止撞抽拉床 |

## 🧩 可拆 / 年审恢复

- 三体块均为独立箱体，角码 + 螺栓压地台预埋点（M8 爬地螺母 / L-track）。
- 湿区：地漏软管**快接**、进水**快接**、便携马桶不接管、浴帘可摘 → 整柱可抬走。
- 台面：进出水快接 → 柜体可整体拆。
- 年审松螺栓、断快接，恢复空车。

## 💨 通风（不动车顶）

- 站浴蒸汽大，必须强排：**侧壁 12V 管道风扇** → 就近可开侧窗 / 侧壁百叶。
- 洗后**刮水器刮干 + 抹布擦壁**是防霉底线，配合开门对流。

## ❓ 待确认（下一步细化）

1. 床基座高度 & 右排床段柜顶高度的**实测值**（决定台阶落差）。
2. 铺位实际长宽——横躺是否需侧壁凹槽借长。
3. 台面段相对滑门门洞的**精确落位**（确保不挡开口）。
4. 二排座椅是否可旋转当餐椅（决定中段要不要另设餐桌）。
