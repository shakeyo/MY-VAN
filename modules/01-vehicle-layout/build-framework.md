# 框架与内饰

## 模块化框架

- **材料**: 2020/2040/2060 欧标铝型材，壁厚 ≥ 1.5mm
- **连接工艺**:
  - 十字横向：穿孔后螺杆连接
  - 纵向：弹簧垫片 + 螺丝
  - 外部：手拧螺丝实现快拆
- **异响控制**: 铝型材连接处增加塑料垫片，所有接触面软连接
- **碰撞安全**: 铝型材框架必须加装横向拦阻纵向梁的结构，防止急刹车侵入

## 通用锚固

- 地台三明治层内预埋 M8 爬地螺母 / T 型螺母（或铺 L-track 航空滑轨），打网格点位
- 各体块底框用角码 + 螺栓压紧预埋点
- 进出水、排水一律走快接，便于整体拆卸

## 驾驶室翻新

- [x] 隔音保温：止震、软垫、防潮垫、隔音棉、TPE 脚垫
- 内饰配色：
  - 方案一：米白色/浅米色皮革
  - 方案二：深棕色/咖啡色
