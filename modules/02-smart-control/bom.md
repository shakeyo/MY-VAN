## 购买检查清单

按以下顺序采购，降低返工风险：

1. [ ] **第一批（必购）**: ESP32 + MAX485 + 继电器模块 ×2 + 稳压模块 + 按钮 + 双绞线
2. [ ] **第二批（布线）**: 阻燃电线 + 端子 + 热缩管 + 防水盒 + 电容
3. [ ] **第三批（传感器）**: 温湿度 + 水位 + 门磁（按需）
4. [ ] **第四批（影音监控）**: DVR + 摄像头 + DSP + 扬声器（可与智能系统并行施工）
