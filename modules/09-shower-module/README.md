# 淋浴模块

帘式湿区 + 快拆防水盘，解决房车淋浴空间与日常活动的矛盾。固定式淋浴房占用面积过大（至少 0.6m²），对 V80 短轴车型不现实。帘式方案淋浴时拉开，平时收起，同一块地面既是过道又是淋浴区。

**核心思路**：用时展开、用完消失。防水帘沿顶部滑轨拉开围成湿区，防水盘快拆设计方便年审恢复。排水重力自流至灰水箱，无需电动排水泵。
