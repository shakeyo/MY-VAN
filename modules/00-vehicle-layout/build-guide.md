# 施工指导：整车布局与结构

## 🛠️ 施工概览

本笔记记录了房车改装过程中的底盘整备、地板铺设、框架施工、保温隔热及驾驶室翻新的详细工艺流程。

## 🚐 阶段一：底盘与车外施工 (Chassis & Exterior)

### 1. 底盘整备
- **防锈修复**: [x] 全车防锈、钣金修复。
- **高压清洗**: 车底喷涂装甲漆。

### 2. 车外施工 (Roof & Paint)
- **车顶锈穿处理**: [x] 打磨、铁锈转化、环氧底漆、钣金胶补洞。
- **全车喷漆**: 方案推荐白色 (70%) + 其他对比色 (30%)。
- **太阳能/行李架**: 详见 [车顶平台与太阳能系统](../06-roof-platform/design.md)。

## 🧱 阶段二：地板与保温隔热 (Flooring & Insulation)

### 1. 地板施工
- **防锈基础**: [x] 喷铁锈转化剂、环氧底漆、水性金属漆。
- **龙骨设计**: [x] 主龙骨固定原车孔，副龙骨找平 (1cm 木方 + 止震板)。
- **保温铺设**: [x] 条贴止震板、2cm XPS 挤塑板、填缝发泡胶。
- **面层安装**: [x] 9mm 海洋板副地板、[x] SPC 石塑地板。

### 2. 两侧与吊顶
- **三明治结构**: [x] 止震板 + XPS 保温 (双面铝箔) + 聚酯棉 + 温莎吸音棉 + 饰面板。
- **吊顶方案**: [x] 原车吊顶清洗、[ ] 翻毛皮包覆、[ ] 吊包导轨安装。

## 🛋️ 阶段三：框架与内饰 (Framework & Interior)

### 1. 模块化框架
- **材料选择**: 2020/2040/2060 欧标铝型材，壁厚建议 1.5mm 以上。
- **连接工艺**:
  - 十字横向：穿孔后螺杆连接。
  - 纵向：弹簧垫片 + 螺丝。
  - 外部：手拧螺丝实现快拆。

### 2. 驾驶室翻新 (Cab Renovation)
- **隔音保温**: [x] 止震、软垫、防潮垫、隔音棉、TPE 脚垫。
- **内饰配色**:
  - 方案一：米白色/浅米色皮革（和谐统一）。
  - 方案二：深棕色/咖啡色（高级撞色）。

## 💡 专项功能模块笔记 (Functional Modules)

### 1. 智能化排风系统
- **硬件**: 利民 12cm 风扇 (x4/x9)。
- **安装**: 亚克力定制面板固定，集成 PWM 调速器。

### 2. 厨房与 IGT 系统
- **结构**: 250x360mm 单元化设计，中门柜下翻门扩展。
- **扩展**: 挂接 IGT 桌轨道，适配茶具、水槽、电磁炉。

### 3. 车窗与遮光方案
- **结构**: 铝箔气泡膜 (外层) + 钕铁硼强磁 (中间) + 毛毡板 (内层)。
- **工艺**: 裁剪需比窗框大 1-2cm，磁吸固定于车窗金属框。

### 4. 多功能折叠卡座 (Dinette)
- **骨架**: 使用 2040 型材立放作为主承重梁，2020 作为立柱。
- **折叠机构**:
  - 顶板分段：350mm 固定段 + 200mm 翻转段。
  - 支撑：使用重载折叠角码或滑轨支撑翻转段。
- **冰箱安装**:
  - 抽拉式：安装 53 宽带锁止重型滑轨。
  - 散热：箱体侧面需开百叶窗孔位，并加装 12V 散热风扇。
- **背板调节**: 使用 K 型多级调节支架，实现 90-120 度靠背倾角。

## 🏗️ 阶段四：功能体块施工（布局落地）

> 布局决策与朝向见 [design.md](./design.md)。三体块均做成独立箱体，螺栓压在地台预埋点上，可单独拆走（年审恢复空车）。

### 通用锚固
- 地台三明治层内**预埋 M8 爬地螺母 / T 型螺母**（或铺 L-track 航空滑轨），打网格点位。
- 各体块底框用角码 + 螺栓压紧预埋点；进出水、排水一律走**快接**，便于整体拆卸。

### 1. 后横床（左基座 + 向右抽拉）
- **固定基座**靠左墙，箱体内做储物；顶板分块可揭或做排骨架/透气孔防潮。
- **抽拉机构**：向右抽出段用**重型三节滚珠滑轨**（成对承重 ≥120kg，加长款），装在基座内壁。
- **抽出段前缘装折叠腿**，落点踩右排"床段"柜顶（等高）；**禁止靠滑轨悬臂扛人**，长期会塌——安全项。
- 右排尾段柜顶必须与床基座**齐平**，否则拼不成整张床。

### 2. 帘式湿区（全高帘柱，居中）
- **防水盘 70深×100宽**：多层板打底 + GRP 一体糊制（或成品淋浴盆改）；单角地漏、**2–3% 找坡**；盘边**上翻 3–5cm 挡水唇**，与地板接缝压防水收口条，水锁死盘内。
- 盘嵌入三明治地台做平，白天走人不绊脚。
- **壁板**：贴墙/贴柜两面做 PVC 结皮板 / 铝塑板防溅（≥1.2m），阴角打 Sikaflex 密封；另两面走 **L/U 形浴帘轨 + 配重帘**。
- **朝过道切倒角**：帘柱靠过道的角做成斜切面，通行不磕。
- **排水**：地漏 → 软管**快接** → 灰水箱（年审拔堵头拆走）。
- **通风**：侧壁 12V 管道风扇排到可开侧窗/侧壁百叶（不动车顶）；洗后刮水 + 擦壁防霉。
- **马桶**：便携式（Thetford Porta Potti 类），平时收角落龛位，用时拉进盘里，不接管。

### 3. 右侧阶梯柜排（中门→尾门）
- **台面段（近中门）**：柜顶抬到 **70+ cm**；台面竹拼板/人造石/多层板贴防火板，边缘做滴水线；嵌小型台下水槽（12V 泵 + 清水箱 → 龙头，排水 → 灰水箱，进出快接）+ 嵌入式电磁炉；深度 **≤40cm** 防撞抽拉床。
- **床段（近尾门）**：柜顶 = 床基座高，兼作夜间床右半张；箱内储物。
- **滑门避让**：柜体在 V80 门洞（约 1m）前后错开，**严禁挡住有效开口**（搬运 + 逃生）。

## ⚠️ 施工安全与注意事项

- **电路**: 详见 [电力系统设计](../01-power-system/design.md)。
- **异响控制**: 铝型材连接处增加塑料垫片，所有接触面使用软连接。
- **碰撞安全**: 铝型材框架必须加装横向拦阻纵向梁的结构，防止急刹车侵入。
- **床抽拉段**: 必须落折叠腿支撑，禁止滑轨悬臂长期扛人。
- **湿区防水**: 挡水唇 + 快接排水是年审可拆前提；不通风必霉，侧壁强排 + 刮干不可省。
