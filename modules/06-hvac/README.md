# HVAC 系统

驻车空调、柴油暖风、换气扇的选型与安装。房车 HVAC 的特殊约束：驻车时不能用原车空调（需发动机运转），因此必须独立制冷/制热；车内空间小（~10m³），温度变化极快，设备功率需要匹配而非越大越好。

**核心思路**：制冷走顶、制热走地、换气走中。冷气下沉从顶棚出风，暖气上升从地板出风，换气扇在中部形成对流。能效优先——空调选变频、暖风用柴油（热值高且与车辆共用燃油）。
