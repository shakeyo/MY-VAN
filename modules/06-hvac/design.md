# 设计决策：HVAC 系统

## 方案概述

房车暖通空调系统，覆盖制冷、制热、通风换气。

## 子系统

| 子系统 | 说明 | 状态 |
|--------|------|------|
| 驻车空调 | 停车时制冷 | 待选型 |
| 柴油暖风 | 驻车制热 | 待选型 |
| 换气扇 | 双向换气 | 待选型 |
| 温控风扇 | 12V PWM 调速 | 待选型 |

## 制冷

- **驻车空调**: 类型待定（顶置式 / 底置式 / 分体式）
- **供电**: 见 [04-power-system](../04-power-system/)

## 制热

- **柴油暖风**: 独立柴油加热器
- **安装位置**: 待定（通常安装于底盘或柜内）
- **进排气**: 需车身开孔，燃烧室进排气独立于车内

## 通风

- **换气扇**: 双向，可进可排
- **温控风扇**: 12V PWM，利民 12cm ×4-9 个
- **安装**: 亚克力定制面板固定，PWM 调速器控制
- **淋浴排风**（侧壁管道风扇，不动车顶）：见 [09-shower-module](../09-shower-module/)

## 控制

- 接入 [10-smart-control](../10-smart-control/) 485 总线
- 温度传感器联动：自动制冷/制热/通风
