# 设计决策：影音娱乐

## 方案概述

全车影音娱乐系统，覆盖显示、投影、音响和交互设备。操作系统复用 [10-smart-control](../10-smart-control/) 的 N100 盒子（Windows）。

## 子系统

| 子系统 | 说明 | 状态 |
|--------|------|------|
| 投影幕布 | 卷轴式，中部安装 | 待设计 |
| 投影仪 | 车尾顶棚快装支架 | 待设计 |
| 显示器 | 右侧台面靠尾门，显示器支架固定 | 待设计 |
| 操作输入 | 键鼠 + 收纳位置 | 待设计 |
| 全车音响 | 主机、功放、喇叭、布线 | 待设计 |

---

## 1. 投影幕布

- **类型**：卷轴式（手动或电动拉幕）
- **安装位置**：车中部（湿区帘轨前方或帘轨上方，幕布降落不挡过道）
- **幕面尺寸**：待定（受车内宽 ~175cm 限制，幕布宽度接近内宽）
- **收纳**：卷轴贴顶棚安装，与吊顶整合

## 2. 投影仪

- **安装方式**：车尾顶棚快装支架（可拆卸，年审隐藏）
- **投射距离**：尾门到中部幕布，待实测确认
- **供电与信号**：取电 10-smart-control 的 N100（HDMI + USB 供电），预埋 HDMI 线从尾部到 N100
- **校正**：优先选用支持侧投/梯形校正的机型

## 3. 显示器

- **安装位置**：右侧台面靠尾门区域，显示器支架固定于台面或侧壁
- **用途**：日常使用（不拉幕时），也可作为投影的第二屏
- **信号**：HDMI 从 N100 引出，预埋走线
- **收纳**：支架可折叠/旋转贴墙，不影响台面操作和床抽拉

## 4. 操作输入

- **键盘**：紧凑型无线键盘（60% 或 TKL），收纳于台面下方抽屉或侧壁挂位
- **鼠标**：无线鼠标，台面操作
- **补充**：可考虑带触控板的迷你无线键盘作为投影场景的遥控
