# 设计决策：外观装饰

## 方案概述

统一房车外观视觉语言，明确拉花、贴纸、装饰件的设计原则、位置关系、材质工艺与落地顺序。

- **风格定位**：复古功能车基底 + 轻越野旅居气质 + 克制的品牌识别
- **车身底色**：白色
- **核心策略**：通过中低位横向拉花、黑色装饰件与少量点状贴纸，压低视觉重心

## 外观关键词

- 复古 / 功能感 / 旅居感 / 干净克制
- 低重心视觉 / 黑白暖色对比

## 1. 拉花方案

采用三段式横向复古色带：

| 层 | 颜色 | 色值 | 宽度 |
|----|------|------|------|
| 上层 | 明黄色 | #F2D21B | 50–60mm |
| 中层 | 橙色 | #F57C00 | 50–60mm |
| 下层 | 红色 | #E53935 | 60–75mm |

- 色带间距：6–10mm，总高度 180–230mm
- 辅色：哑黑 / 半哑黑
- 禁用：荧光色、电镀色、大面积镜面银

### 位置

- 整体较原车拉花位**下移 80–150mm**
- 底部红色带落在后轮轮眉最高点水平线附近（±30mm）
- 中部橙色带与侧滑门把手下沿平行
- 顶部黄色带与车窗下沿有明确留白

### 延展范围

- 尾灯前方 80–120mm → 贯穿后侧围、滑门、中门 → 前门缝后方 100–180mm 收尾
- 不拉满到前翼子板

### 线条处理

- 纯直线，经过门缝精确对位
- 经过门把手从下方通过
- 收口做平切或小圆角

## 2. 贴纸方案

### 主识别贴纸（1 组，位置二选一）
- 方案 A：前门下半部，拉花上方
- 方案 B：后侧窗后方白色区域
- 内容：车名 + 英文副标 + 极简图形符号
- 主标题高 60–90mm，副标高 18–28mm
- 哑面户外车贴，不反光

### 功能贴纸
| 位置 | 内容 |
|------|------|
| 充电口 | 220V / Solar / DC |
| 注水口 | Fresh Water |
| 排污口 | Waste / Drain |
| 检修位 | Power Access |
| 外置接口 | Shower / Inlet / Service |

- 高度 12–20mm，统一无衬线字体，深灰或黑

### 情绪贴纸（≤2 组）
- 山脉线稿、经纬度、小号 "Overland / Roam / Home on Wheels"
- 禁止：卡通、多品牌混贴、口号堆叠、过多徽章

## 3. 装饰件

| 部位 | 方案 | 备注 |
|------|------|------|
| 轮毂 | 哑黑，简洁钢轮感 | 压低重心，禁用亮银 |
| 侧踏板 | 黑色，哑面 | 禁用镀铬 |
| 窗框/雨挡 | 半哑黑 / 原厂黑塑料 | 与玻璃暗色区连成整体 |
| 遮阳棚 | 黑色外壳 | 长度与侧窗协调 |
| 车顶件 | 黑色铝型材/喷粉 | 薄、低、整洁 |
| 爬梯 | 哑黑，直线造型 | 优先车尾 |
| 前脸 | 中网局部黑化，车标低调 | 不加镀铬 |
| 尾部 | 呼应侧面的识别贴 | 外挂件统一黑色 |

## 4. 材质与工艺

- **拉花**：铸造级车身贴膜（3M / Avery Dennison 同级），哑面，3 年以上耐候
- **贴纸**：户外耐候车贴，防 UV 防雨淋，可局部替换
- **装饰件**：金属件优先黑色喷粉，塑料件统一哑黑，结构件不保留裸金属
