# 外观装饰

车身外观是房车成品的"第一眼"。V80 原厂素车外观偏商用，通过三段式拉花、轮毂黑化和装饰件，让整车呈现统一风格，同时兼顾年审时部分装饰可快速复原。

**核心思路**：低成本、可逆。拉花用户外级车贴，不喷漆（保留原厂漆面），轮毂用可撕喷膜而非烤漆。年审时关键件可移除。
