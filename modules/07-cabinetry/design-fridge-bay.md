# 二排前冰箱位（型材框架 + 兼小孩脚踏）

## 方案概述

上开门卧式 12V 冰箱装于**二排座椅前方**（正对安全座椅），型材框架箱体。顶面为可掀软垫盖板，行驶中兼作小孩脚踏（脱鞋踩）；驻车时掀盖取物。用掉驻车闲置的前部空间，同时把噪音源移出睡眠区（原中段位让给衣帽区，见 [design-wardrobe.md](design-wardrobe.md)）。

## 设计参数

| 项目 | 参数 | 说明 |
|------|------|------|
| 冰箱形式 | 上开门卧式 12V | 前开门立式门板与小孩腿打架，不选 |
| 箱体高度 | 35~45 cm | 车载卧式冰箱常见高度，顶面 ≈45cm 兼脚踏 |
| 脚踏 | 顶盖 + 2~3cm 软垫，铰链朝车头可整体掀开 | 幼儿腿短可前置 10cm 矮踏台过渡 |
| 锚固 | M8 螺栓 ×4 压地台预埋点 | 满载 ~20kg，碰撞中必须是固定件不是抛射物 |
| 通风 | 箱体两侧留 ≥2cm 通风槽 | 顶面被脚踏占用，散热路径只剩侧面 |
| 供电 | 12V 常电 + 低压保护 | 走 [04-power-system](../../04-power-system/) |

## 结构

```
行驶中（顶盖放下）：
     ┌──────────┐  ← 软垫盖板（脚踏，脱鞋踩）
     │ 卧式冰箱  │
     └──────────┘
     ▲ M8 锚固压地台预埋点

驻车取物（掀盖）：
     ┌──────────┐  ← 铰链朝车头，整块掀起
     │ 卧式冰箱  │
     └──────────┘
```

## 安装要点

1. **先定安全座椅位，再定冰箱位**：箱体正对小孩脚的方向，让孩子试坐定脚踏高度（腿自然屈膝、脚掌平落）。
2. **锚固必须做**：M8 爬地螺母压地台预埋点，不能只靠框架自重。追尾时未锚固的满载冰箱会向后飞向安全座椅，锚固后它反而兼当腿托保护结构。
3. **通风不能省**：卧式冰箱冷凝器在侧/后，箱体两侧留 ≥2cm 通风槽；顶面被封后散热路径只剩侧面，通风差会导致压缩机过热高速运转（更吵、更耗电）。
4. **软垫整块可掀**：铰链朝车头方向，驻车时站在座椅旁一掀即取物；垫子做成一整块（2~3cm 软垫 + 背板），不要分小块。
5. **年审可拆**：框架螺栓固定、冰箱走快接插头，随体块一并拆走恢复空车。

## 已接受的代价

- 做饭取食材、夜里喝水都要走到车头（2.6m 的车，三四步）
- 行驶中取饮料不便
- 换来：睡眠区绝对安静 + 中段让给衣帽区（衣服动线最优）
