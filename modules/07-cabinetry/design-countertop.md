# 右侧台面段

## 方案概述

沿右侧车身从前到后（中门→车尾）的通长台面，分三段，深度和功能各有侧重。台面下方为柜体储物（见 [design-bed-cabinet.md](design-bed-cabinet.md)），上方为操作面。水槽和 IGT 模块区均配可拆卸盖板，盖上后为完整平面，办公/做饭模式自由切换。

## 1. 分段尺寸

```
中门 ←────────────────────────────────────────────────────→ 车尾

┌──────────┬─────────────────┬──────────────────────────────┐
│  中门段   │     中间段       │       后床上方段 ~130         │
│  28深     │      40深        │         40深                 │
│  40长     │   水槽 36×38     │  2×IGT  ~50  │  平面  ~80    │
│           │                 │              │  (显示器/办公) │
│ 饮用水桶  │   柜体储物       │  做饭区       │  办公区        │
│ (下方)    │                 │              │               │
└──────────┴─────────────────┴──────────────┴───────────────┘
     ↑             ↑                ↑               ↑
  滑门旁         座椅后方        床段柜上方       靠尾门
  (与座椅并排)   (不受座椅限制)
```

| 段 | 深度 | 长度 | 用途 | 下方 |
|---|---|---|---|---|
| 中门段 | 28 cm | 40 cm | 置物台面 | 立式饮用水桶 |
| 中间段 | 40 cm | ~60-70 cm | 水槽（36×38 cm） | 柜体储物 |
| 后床上方段 | 40 cm | ~130 cm | IGT 做饭区（~50 cm）+ 办公平面（~80 cm） | 床段柜顶（柜内储物） |

> 分段长度待现场按车厢内空、座椅位置、中门开口实测后精确确定。

## 2. 台面高度

- 站立操作高度：**80-85 cm**（待实测确认）
- 与周边关系：台面下方为独立柜体，不与床段柜顶同高（床面 ~45 cm）
- 中门段高台面下留出饮用水桶放置空间（桶高 ~50 cm，桶上方为台面底面）

## 3. 各段设计

### 3.1 中门段（28×40 cm）

最窄段，与折叠座椅并排。台面下有 50+ cm 净高放置立式饮用水桶（桶嘴朝上，手压泵或电动抽水器取水）。

- 台面仅做置物，不装水槽或炉头
- 材质与相邻段一致

### 3.2 中间段 — 水槽（40 深）

安装台下盆水槽（36×38 cm），配 **可拆卸盖板**。盖板盖上后台面平整，可做置物或备菜区。

| 项目 | 参数 |
|------|------|
| 水槽尺寸 | 36×38 cm，台下安装 |
| 盖板 | 同材质台面余料，底部贴防滑垫，直接搁在槽口 |
| 水槽收纳 | 盖板取下后插在柜体侧面收纳槽内 |

### 3.3 后床上方段 — IGT 模块区（~50 cm）

台面开出 IGT 兼容槽，**2 个 1U 单元并排**。槽内四周做支撑唇边（铝型材或硬木条），IGT 单元直接搁在上面，不买专用框架。配一块可拆卸盖板，盖上后与相邻平面连成整体办公台面。

```
IGT 槽剖面（正面）：
┌─────────────────────────────┐
│         台面                 │
│  ┌─────────────────────┐    │
│  │  IGT 1U  │ IGT 1U   │    │  ← IGT 单元搁在支撑条上
│  │  (炉头)  │ (砧板/   │    │
│  │          │  储物盒)  │    │
│  └──┬───────┴─────┬────┘    │
│     └─────────────┘         │  ← 支撑唇边（2020 铝型材或 15mm 木条）
├─────────────────────────────┤
│         柜体内部             │
```

**IGT 适配要点**：

| 项目 | 做法 |
|------|------|
| 槽口尺寸 | 按实际 IGT 单元尺寸 + 2mm 间隙（建议先买到单元再开槽） |
| 支撑唇边 | 2020 铝型材横撑或 15×15mm 硬木条，缩进槽口内 5mm，IGT 单元外框搁在上面 |
| 盖板 | 同材质台面余料，尺寸 = 槽口外轮廓，底部贴防滑垫 |
| 盖板收纳 | 取下后插在台面下方滑槽或柜体侧面 |
| 气管孔 | 槽底开 φ25mm 穿线孔 → 下方柜体 → 高山气罐（柜内固定座） |
| 散热 | IGT 炉头下方柜体不做封闭，保留通风间隙 |

> **关键**：IGT 单元取出用于户外厨房时（见户外厨房设计），盖板盖上，台面恢复完整。同一个炉头室内室外通用，不重复购买。

### 3.4 后床上方段 — 办公平面（~80 cm）

完整平面，无开孔。用于放置显示器、键盘、鼠标，日常办公区域。

- 显示器支架固定于台面或侧壁（靠近尾门端）
- 台面下方走 HDMI + USB 线至 N100 主机（见 [10-smart-control](../10-smart-control/)）

## 4. 台面材质与工艺

| 选项 | 优点 | 缺点 |
|------|------|------|
| 竹拼板（推荐） | 硬度高、防水、纹理好看、可自己开槽 | 重量中等 |
| 海洋板 + 防火板贴面 | 轻、便宜、可 DIY | 封边要求高，遇水易胀 |
| 人造石 / 石英石 | 无缝、高级感 | 重、不可 DIY 开槽、贵 |

> 推荐竹拼板 18-20mm 厚，水性清漆封两遍。边缘倒圆角 + 滴水线。

## 5. 柜体结构

台面下方为铝型材框架 + 柜门，详见 [design-bed-cabinet.md](design-bed-cabinet.md)。台面通过角码 + 螺栓固定在框架顶梁上，可拆卸。
