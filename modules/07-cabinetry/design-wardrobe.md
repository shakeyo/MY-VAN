# 中段衣帽柜（行李箱竖放 + 抽屉）

## 方案概述

床与二排座椅之间的中段位（原湿区 → 后改冰箱位 → 现定衣帽区），利用既有铝型材框架分格：**底部行李箱竖放 + 上部抽屉/搁板**。行李箱装大件/备量衣服（长途旅行整箱搬，年审/换季直接拎下车），抽屉放每日内衣袜子等小件——每天早晚取小件不用开箱。

## 设计参数

| 项目 | 参数 | 说明 |
|------|------|------|
| 占位 | 70 深 × 100 宽（车长 × 车宽） | 与既有型材框架一致 |
| 底部箱格 | 内空高 **≥75 cm** | 28 寸箱带轮 ≈73cm，竖放 |
| 箱格宽度 | 2 箱并排 ≈90cm，或 1 箱 + 抽屉柱 | 按实际箱子数量定 |
| 上部抽屉 | 1~2 层（75~150cm 区间） | 每日小件 |
| 箱门朝向 | 朝过道 | 站在过道翻箱，开盖需 ~60cm 净空（箱前余量 + 过道） |

## 结构

```
┌────────────────────┐
│ 抽屉/搁板 ×1~2      │  ← 每日内衣袜子、小件
│                    │
│ 行李箱竖放（28寸）  │  ← 大件/备量衣服，箱门朝过道
│ 0~75cm             │
└────────────────────┘
    ↑ 内空高 ≥75cm（按实车框架高度核实）
```

## 安装要点

1. **先量箱**：按家里实际箱子的尺寸（含轮子把手）定格高，28 寸 ≈68~73cm。
2. **框架复用**：原冰箱位框架直接改分格（T 槽加横梁/层板），不重搭。
3. **箱格留余量**：箱子竖放进出需要左右 1cm 余量，别做卡死。
4. **抽屉深度 ≤45cm**：70cm 进深做满抽太重，45cm 抽 + 背后藏不常用物更顺手。
5. **上部做抽屉不做开放搁板**：行车颠簸搁板上的东西会飞，抽屉自带围挡。
