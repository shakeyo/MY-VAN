# 后横床

## 方案概述

铝型材翻折床，适用于后横床布局（宽 1.35m）。左右两块 9mm 海洋板平时分别为床侧立板和柜侧下翻门，睡觉时翻平对接成整张床面。立柱内退 + 板子外凸，机构完全隐藏；气弹簧辅助，单人可独立完成展开与收起。

基座高度与右侧床段柜顶平齐（见 [07-cabinetry](../07-cabinetry/design-bed-cabinet.md)），锚固点由 [01-vehicle-layout](../01-vehicle-layout/) 预埋。

---

## 1. 设计参数

| 项目 | 参数 | 说明 |
|------|------|------|
| 平台总宽 | 1350 mm | 后横床宽度 |
| 床面深度 | 1900 mm | 按实际车厢内长调整 |
| 左板尺寸 | 宽 600~700 × 深 1900 mm | 床侧开口实测后确定 |
| 右板尺寸 | 宽 650~750 × 深 1900 mm | 柜侧开口实测后确定 |
| 板厚 | 9 mm 海洋板 | 已有材料 |
| 立柱内退 | 40 mm | 为折叠支架收起预留隐藏空间 |
| 板子外凸 | 40 mm | 板子比立柱安装面宽出 40mm，遮住后方所有机构 |
| 单块板重量 | ~12-15 kg | 含加强筋，一人可搬动 |
| 床面高度 | 400~500 mm | 与右侧床段柜顶同高 |

## 2. 总体结构

```
平时（收起）：
┌─────────┐        ┌─────────┐
│   床    │  过道  │   柜    │
│  ┃左板┃ │        │ ┃右板┃ │
│  ┃(垂直)┃│        │ ┃(垂直)┃│  ← 两块板外凸 40mm 边遮住后方所有机构
│  ↑立柱    ↑      │ ↑立柱    ↑
│   +折叠支架(收)   │  +折叠支架(收)
└─────────┘        └─────────┘

睡觉时（展开）：
┌─────────┐══════════════════════════┐
│   床    │      左板  ───  右板      │
│         │═══════════╤══════════════│
│ 左板3个 │  ←左板边缘  │  铰链+承托条  │
```

## 3. 左板系统（上翻）

### 3.1 翻转方式

- **铰链**：钢琴铰链（长排合页），装在板子底边与床架底部铝型材之间
- 板子从垂直状态向上翻起 90° 至水平
- 铰链轴高度 = 床面设计高度，与右板铰链轴**严格同高**

### 3.2 板子加强

板子背面贴 2 根 2020 铝型材（长度 1900 mm），自攻螺丝从板面拧入型材 T 槽：

```
板子背面（俯视图）：
┌────────────────────────────────┐
│════════════════════════════════│  ← 2020 加强筋（距板子前缘 80mm）
│                                │
│════════════════════════════════│  ← 2020 加强筋（距板子后缘 80mm）
│  ○      ○      ○              │  ← 3 个支架固定点（拧在加强筋上）
└────────────────────────────────┘
```

### 3.3 支撑与锁定

| 部件 | 规格 | 数量 | 安装方式 |
|------|------|------|----------|
| 重型折叠支架 | 不锈钢，带 90° 自锁，展开长 250~300 mm | 3 个 | 底座 T 型螺母固定在内退立柱上，活动端固定在板子背面加强筋 |
| 上翻气弹簧 | 推力 35 kg (350 N)，总长 400 mm，行程 200 mm | 2 根 | 上端固定在内退立柱（距铰链轴 400~500 mm），下端固定在板子背面（距铰链轴 150~200 mm） |

板子翻平后展开支架自动锁定，形成三角支撑。气弹簧使板子向上推时托住、任意角度悬停。

### 3.4 收起固定

- 板子垂直贴向立柱后，用 **2 个强力磁吸**（≥10 kg 级）吸合固定
- 磁吸片装在立柱上，铁片装在板子背面

## 4. 右板系统（下翻 + 搭接承重）

右板不靠自身支架承重，而是**落在预开支架和左板边缘上**，载荷全部经左板支架传至立柱。铰链仅承担翻转导向和垂直悬挂，不承受睡姿负载。

### 4.1 受力路径

```
人体重量
  │
  ▼
右板 ──┬──→ 铰链侧：2020 承托条（柜体框架）──→ 柜体立柱
       ├──→ 中间：左板边缘（45° 搭接 + 定位销）──→ 左板支架（压缩）──→ 左立柱
       └──→ 自由边：预开折叠支架（压缩）──→ 右立柱
```

三个支点全部在压缩方向受力，没有拉伸或弯曲。

### 4.2 翻转方式

- **铰链**：钢琴铰链，装在板子顶边与柜体框架（桌面/顶板下沿）之间
- 板子从垂直状态向下翻开 90° 至水平
- 铰链轴高度必须与左板铰链轴**严格同高**（误差用铝垫片调节）

### 4.3 铰链侧承托

柜体框架上、铰链正下方装一根 **2020 铝型材承托条**（内退一个板厚 9mm）。右板翻平后，铰链侧边缘刚好搁在上面，防止人睡在靠柜体一侧时板子以左板边缘为支点翘起。

```
柜体侧剖面（右板翻平后）：
┌──────────┐
│  柜体    │
│  框架    │
│          │
│  ← 铰链  │
├──────────┤──── 右板（水平，9mm 海洋板）
│ 承托条   │  ↑ 板子边缘搁在承托条上
│ (2020)  │
└──────────┘
```

### 4.4 自由边支撑（预开折叠支架）

在右立柱（内退 40mm）上安装 **2~3 个重型折叠支架**，支架活动端**不与板子固定**。展开前手动打开支架到水平位（90° 自锁），右板翻下来后直接落在支架上。收起时先翻起板子，再把支架折回立柱内侧。

```
右立柱（正视图，板子收起时）：
        ┌──────┐
        │ 立柱 │
        │      │
        │  ◸   │  ← 支架折回，隐藏在内退 40mm 空间内
        │  ◸   │
        │  ◸   │
        └──────┘

右板翻平后（俯视）：
        ┌──────┐
        │ 立柱 │
        ├──┬───┤──── 右板
        │◺ │   │  ↑ 板子搁在支架上，不固定
        ├──┼───┤
        │◺ │   │
        ├──┼───┤
        │◺ │   │
        └──┴───┘
```

> 支架与板子之间**不锁螺丝**。重力+床垫压住已足够稳定，不固定也方便操作——展开时不用钻到板子底下拧任何东西。

### 4.5 板子加强

- **纵向**：2 根 2020 铝型材（1900 mm），同左板
- **横向**：1 根 2020 铝型材（长度 = 右板宽度 − 40 mm），连接两根纵筋形成"日"字框，防止下翻时前后翘曲
- 右板背面**不需要**支架固定点，加强筋仅用于板子自身刚性

### 4.6 下翻阻尼

| 部件 | 规格 | 数量 | 说明 |
|------|------|------|------|
| 下翻阻尼气弹簧 | 拉力/阻尼 30 kg (300 N)，总长 350 mm，行程 180 mm | 2 根 | 上端固定在柜体顶梁，下端固定在板子背面靠上 1/3 处 |

气弹簧提供下翻阻力，板子缓慢下降落在支架上，不会突然砸下。收起时辅助回拉。

### 4.7 收起固定

- 垂直收起后，板子底部用 **2 个强力磁吸**吸合在柜体下横梁上
- 外凸 40 mm 边完全遮住后方立柱、支架和承托条，外观就是平整的柜门

## 5. 中间对接

两块板放平后在过道中间对接，必须共面且不错位：

| 项目 | 做法 |
|------|------|
| 接缝处理 | 左板右侧边、右板左侧边各做 45° 倒角，拼合后呈 V 型细缝，铺上床垫完全无感 |
| 防错位 | 左板右边缘装 2 个 φ8 铝定位销（长 15 mm）；右板左边缘开对应定位孔。放平时销插入孔中锁定 |
| 高度微调 | 若两块板顶面有细微高低差，通过左板铰链底座下加铝垫片（1~3 mm）调节 |

## 6. 操作流程

单人即可完成，全程板子不会失控坠落，也不需要钻到板子底下操作。

### 展开（睡觉）

1. 走到右侧 → 手动打开右立柱上的 2~3 个折叠支架到水平位（90° 自锁）
2. 走到左侧 → 解除左板磁吸 → 单手向上推 → 气弹簧托着板子缓升至水平 → 展开 3 个支架锁定
3. 走到右侧 → 解除右板磁吸 → 单手向下放 → 气弹簧拉着板子缓降 → 落在预开支架和左板边缘上
4. 确认定位销插入、中间接缝齐平
5. 铺床垫

### 收起（起床）

1. 撤床垫
2. 走到右侧 → 单手向上翻右板 → 气弹簧辅助回拉 → 推回垂直 → 磁吸固定 → 折叠支架收回立柱内侧
3. 走到左侧 → 解锁左板支架 → 气弹簧托住板子缓降 → 推回垂直 → 磁吸固定

## 8. 安装要点

1. **先装右板，定基准**：右板结构受柜体限制，先确定其水平高度（铰链轴 + 承托条位置），再按同一标高装左板铰链
2. **承托条内退 9mm**：铰链侧承托条安装面比柜体框架外表面内退一个板厚（9mm），确保右板翻平后与承托条齐平
3. **右支架先试装**：右立柱上的折叠支架在 T 槽内滑动试装，确保展开后顶面与左板边缘、承托条三者共面
4. **内退尺寸统一**：左右立柱统一内退 40 mm，板子统一外凸 40 mm，确保外观对称、机构隐藏
5. **气弹簧先调后装**：气弹簧球头座先在型材 T 槽内滑动试装，找到板子水平时气弹簧处于行程中段的位置再锁紧
6. **支架避开气弹簧**：板子背面的支架固定点与气弹簧固定点错开布置，避免干涉
7. **铰链必须承重级**：普通柜门合页扛不住 15 kg 板子反复翻转，必须用不锈钢长排合页或加厚钢琴铰链（轴径 ≥6 mm）
8. **板子倒角在工厂做**：45° 倒角让板材供应商用 CNC 或修边机一次成型，手工倒角很难保证平直度
9. **安装顺序**：柜体框架 → 承托条 → 右板铰链 → 右板 → 右支架 → 左立柱 → 左板铰链 → 左板 → 左支架 → 气弹簧 → 磁吸
