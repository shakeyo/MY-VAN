# 小米平板4 移动中控板

> 状态：**方案规划**（直供电改造暂缓，见下）。
> **位置已调整（2026-09）**：平板**主位改到水槽前壁挂支架**，副位在**额头柜下沿**（3D 打印斜角件，横屏，不做抽拉，见 [tablet-mount.md](tablet-mount.md)），
> 副驾驶位**保留为移动位 / 监控位**，优先级降低。

## 定位

| 位置 | 用途 | 优先级 |
|------|------|--------|
| **水槽前壁挂**（主位，横屏） | 日常控制 + Dashboard 常驻；做饭/洗碗时手边可用 |
| **额头柜下沿**（副位，横屏） | 驾驶区查看/操作 |
| **吊顶悬吊**（副位，横屏） | 坐姿仰视（后床/卡座）；利用已预埋 1/4" 螺纹，**可调角** | ⭐ 主位，见 [tablet-mount.md](tablet-mount.md) |
| 副驾驶（移动位） | Frigate 监控画面；可移到后床旁 | 保留，优先级降低 |
| 后床旁（快拆移动） | 睡前看监控 / 夜间控制 | 保留 |

与安卓车机（壁挂固定、生活区中控）分工：车机是生活区大屏中控，平板是生活区/床位终端，互为备份（Dashboard 多端冗余原则见 [design.md](design.md)）。

> **关于磁吸**：水槽前主位是**常驻固定**场景（车在跑、面板倾斜 22°），
> **纯磁吸不适用**，改「底部托边 + 顶部压边」纯机械固定——详见
> [tablet-mount.md §4.3](tablet-mount.md)。
> 副驾位是**"取下来"**场景，磁吸在那里反而合适。

## 直供电改造（**暂缓**，2026-09 决定）

> **决定：先不拆电池。** 平板在水槽前当**常驻固定面板**，不常取放；
> 夏天高温时整台带走即可。拆机 + NTC 模拟**坑多且不可逆**，
> 收益（免充电）不足以抵消风险，**暂不做**。
> 若将来实测发现常驻充电有问题（如高温胀气、充电管理异常），再回来做本节。

- **（原方案，暂缓）目标**：去掉电池，副电瓶 12V → 5V 直供，7×24 常开
- **供电链路**：副电瓶 12V 常电 → 降压模块（5V 3A+）→ 电池接口
- **已知坑**：小米平板缺电池温度检测（NTC）时可能限流或拒开机——常见做法是保留电池保护板、5V 接保护板输出焊点，NTC 用固定电阻模拟；具体以拆机实测为准
- **当下做法**：保留电池，**USB 常供电 + Fully Kiosk 充电常亮模式**

## 快拆支架

- **水槽前主位**：**非快拆**——常驻固定，见 [tablet-mount.md](tablet-mount.md)（**3D 打印斜角支架挂墙 + 托边/压边机械固定**，倾角 22°）
- **副驾驶位（移动位）**：仪表台/遮阳板侧固定座，**磁吸可行**（这是"取下来"的场景）
- **后床旁**：同规格快拆座，支架通用，换位即插即用
- **供电随座走**（副驾/后床快拆位）：快拆座集成供电触点（磁吸触点或 Type-C 接口）
