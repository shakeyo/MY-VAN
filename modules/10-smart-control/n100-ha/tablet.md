# 小米平板4 移动中控板

> 状态：**方案规划，拆机验证待做**。副驾驶位安装（监控 + 全车控制面板），快拆设计可移到后床旁。

## 定位

| 位置 | 用途 |
|------|------|
| 副驾驶（主位） | Frigate 监控画面 + HA Dashboard 全车控制 |
| 后床旁（快拆移动） | 睡前看监控 / 夜间控制 |

与安卓车机（壁挂固定、生活区中控）分工：车机是生活区大屏中控，平板是驾驶区/床位移动终端，互为备份（Dashboard 多端冗余原则见 [design.md](design.md)）。

## 直供电改造（待拆机验证）

- **目标**：去掉电池，副电瓶 12V → 5V 直供，7×24 常开。拆电池同时消除夏天车内高温的锂电池隐患
- **供电链路**：副电瓶 12V 常电 → 降压模块（5V 3A+）→ 电池接口
- **已知坑（待验证）**：小米平板缺电池温度检测（NTC）时可能限流或拒开机——常见做法是保留电池保护板、5V 接保护板输出焊点，NTC 用固定电阻模拟；具体以拆机实测为准
- **软件**：Fully Kiosk 常亮 + 充电常亮模式；屏幕自动开关策略待定（人体感应 / 按需点亮）

## 快拆支架

- **副驾驶位**：仪表台/遮阳板侧固定座，磁吸或卡扣快拆
- **后床旁**：同规格快拆座，支架通用，换位即插即用
- **供电随座走**：快拆座集成供电触点（磁吸触点或 Type-C 接口），不另外插线
