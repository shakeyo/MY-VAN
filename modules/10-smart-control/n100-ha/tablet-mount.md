# 平板支架（水槽前 + 额头柜下 + 吊顶，3D 打印）

> 状态：**方案设计**（已按平板实测尺寸计算，待现场确认安装高度与净空）。
> **三处安装**：
> ① 水槽下方柜体正面（主位，壁挂，固定倾角）
> ② 额头柜下沿（副位，壁挂，固定倾角）
> ③ **吊顶悬吊（副位，坐姿仰视，必须可调角，可旋下收纳）**
>
> **不做抽拉**，用 **3D 打印支架**；**参数化脚本见 [tablet-mount.scad](tablet-mount.scad)**
> （改数值即出 STL，两处用途共用一个脚本）。

## 一、平板实测尺寸（小米平板4 8"）

| 项 | 值 |
|----|-----|
| 外形 | **200.2 × 120.3 × 7.9 mm** |
| 横屏 | 200.2 宽 × 120.3 高 |
| 竖屏 | 120.3 宽 × 200.2 高 |
| 重量 | ≈ 350 g |

> **三处都用横屏**（200 宽 × 120 高）——仪表 Dashboard 横屏更自然，
> 且横屏"顶部撑出"只有竖屏的一半（见 §三）。

## 二、为什么选这两块位置

**① 水槽下方柜体正面**：水槽盆体占深，这块面板后面放不了东西——天然"废位"。
在操作动线上，走线近，不占储物。

**② 额头柜下沿**：额头柜面板（1440×270mm）本身是喇叭箱体 + 上翻柜门，
**柜门区域不能占**（要能翻开）。**挂在柜底下沿**（贴柜底垂直向下），
不干涉柜门与喇叭。

> ⚠ **额头柜面板本身放不下平板**：面板高仅 270mm，平板 200mm 高，
> 且中间 590mm 是上翻柜门、两侧是 φ170mm 喇叭。
> 横向唯一 ≥200mm 的空间就是柜门本身——**占了就打不开柜门**。
> 所以只能是"**柜底下沿**"，不是"装在面板上"。

## 三、几何计算（横屏）

支架内腔 = 平板 + 每侧 1mm 取放间隙：

| 项 | 值 |
|----|-----|
| 内腔 | **202.2 × 122.3 mm** |
| 外廓（含托边、压边悬垂、壁厚） | **208.2 × 136.3 × 15.9 mm** |
| 腔深 | 7.9（平板）+ 5（托边）+ 3（背板）= **15.9 mm** |

**顶部撑出 D = 支架外廓高 × sin(θ)**：

| 倾角 θ | 顶部撑出 D |
|--------|-----------|
| 15° | 35.3 mm |
| **20°** | **46.6 mm** |
| **22°** | **51.1 mm** |
| 25° | 57.6 mm |

> **水槽前推荐 θ = 20-22°，撑出约 47-51mm。**
> 横屏比竖屏撑出小得多（竖屏要 69-85mm），凸出感明显更好——**这也是选横屏的原因之一**。

## 四、倾角方向：⚠ 别装反

面板位置低（底部 40-50cm）、眼睛高（站立 155cm）→ **眼睛是俯视它的**。
要让**屏幕面朝上后方**（顶沿向人倾出）：

| 面板姿态 | 屏幕法线偏离视线 |
|---------|----------------|
| 垂直（0°） | 20.2° |
| **顶沿倾出 20°** | **2.7°** ✅ |
| 顶沿倾出 30° | 6.3° |
| 顶沿**收进** 20° | 37.3° ❌ |

> **顶沿向人倾出，不是向内收。** 装反了偏离 37°，比不倾斜还差。

## 四之二、⚠ 吊顶位置：方向反转，且**必须可调角**

吊顶（顶棚）是**上下颠倒**的场景，倾角逻辑完全不同：

| | 水槽前（壁挂） | **吊顶（悬吊）** |
|---|---|---|
| 面板位置 | 低（40-70cm） | **高（顶棚 ~200cm）** |
| 眼睛位置 | 高（站立 155cm） | **低（坐姿 ~120cm）** |
| 视线方向 | 俯视 ↓ | **仰视 ↑** |
| 屏幕面朝 | 上后方 | **下前方**（像飞机座椅屏） |
| 倾角方向 | 顶沿**向人倾出** | **底沿向人倾出**（顶沿贴顶） |
| 倾角需求 | **固定 20-22°** 够用 | **14-48°，跨度 35° → 必须可调** |

**为什么吊顶必须可调**（坐姿眼高 120cm、吊顶 200cm，落差 80cm）：

| 人距屏幕下方 | 视线仰角 | 屏幕需向下倾 |
|-------------|---------|-------------|
| 20 cm | 76.0° | 14.0° |
| 30 cm | 69.4° | 20.6° |
| 50 cm | 58.0° | 32.0° |
| 70 cm | 48.8° | 41.2° |
| 90 cm | 41.6° | 48.4° |

> **坐得越远，屏幕要越水平**。从 20cm 到 90cm，所需倾角从 14° 变到 48°
> ——**固定角度做不到**。这正是你说的 **1/4 螺纹 + 球头**的用武之地 ✅

### 吊顶受力（比壁挂严峻）

| 项 | 值 |
|----|-----|
| 平板 + 支架 | ≈ 350 g → **拉力 3.4 N（350 gf）** |
| 重心偏心 8cm → **弯矩 0.27 N·m（2.8 kgf·cm）** |
| 颠簸 2-3g → 等效拉力 **700-1050 gf** | 

> ⚠ **球头是摩擦锁紧**：水平悬吊 + 恒定力矩 → **会缓慢下垂**，比壁挂更明显。
> **必须选带锁紧旋钮的球头**，或用**齿盘式俯仰关节**（咬合自锁，不怕颠簸）。

### 你的 1/4 螺纹预埋：强度要点

| 预埋基体 | 做法 |
|---------|------|
| **木板（顶棚）** | **必须用金属 T 型螺母 / 预埋螺母**；直接对木板攻丝会滑牙，350g 悬吊 + 颠簸会拔脱 |
| **打印件** | 用**热熔铜螺母**（烙铁压入），座体加厚 ≥9mm + 加强筋；不要靠打印螺纹受力 |

> 1/4" = **6.35mm**。相机螺孔标准件便宜好买，球头/云台/延长杆全兼容。

## 五、旋转结构：两种方案对比

> **结论先行**：**水槽前 + 额头柜下用固定楔形（不旋转）**；
> **吊顶必须可调**（1/4 球头带锁紧，或齿盘关节）。

### 方案 A：单轴铰链 + 齿盘锁（**推荐**）

```
        ┌────────────┐
        │   平板壳    │
        └─────┬──────┘
              │ ← 水平轴
        ╔═════╧═════╗
        ║  齿盘咬合   ║  ← 齿盘自锁，调档位
        ╚═════╤═════╝
              │
        ┌─────┴──────┐
        │  墙面底座   │
        └────────────┘
```

| 优点 | 缺点 |
|------|------|
| **齿盘咬合自锁**，颠簸不下垂 | 角度是**档位式**（如每 10°），非无级 |
| 结构简单、强度高、全靠打印件 | 需自己设计齿盘（但很成熟） |
| 绕水平轴 = 调**俯仰**，正对视线 | 换位置要整套一起搬 |
| 无金属件依赖（可用打印销轴） | — |

### 方案 B：壳内置 1/4 螺母 + 球头（你的提议）

| 优点 | 缺点 |
|------|------|
| **任意角度**、无级调节 | 球头靠摩擦锁紧，**颠簸会缓慢下垂** |
| **可整体取下**（拧下球头即拿走） | 1/4 螺母预埋需**加强结构**（否则连根拔出） |
| 球头是成熟商品，几元~几十元 | 多了金属件与装配公差 |
| 两处位置可共用同一个壳 | 球头云台进深较大 |

**承重校核**：平板 350g，力臂按 100mm → 静态力矩约 **0.34 N·m（3.5 kgf·cm）**。
常见 1/4 球头云台额定 1-3kg，**静态足够**；但**颠簸冲击可达 3-5 倍**，
所以必须选**带锁紧旋钮**的球头，或加辅助支撑。

### 方案 C：双轴（俯仰 + 水平旋转）

- 俯仰调角度 + 水平转方向，可竖横屏切换
- 结构复杂、零件多、强度下降
- **只在"两处都用、且要转方向"时才值得**

### 推荐

**水槽前用方案 A**（固定安装、齿盘调角、最稳）；**若你想两个位置共享一个壳、能取下来**，
则用方案 B（1/4 螺母 + 带锁紧球头），代价是颠簸需复查下垂。

> 建议先做**方案 A 的固定楔形版**（连齿盘都不要，直接 20° 一体成型）试用——
> 结构最简单、最稳。**实测确认角度合适后**，再决定要不要上可调结构。
> 换句话说：**先不要旋转，先验证角度与位置**；旋转是"锦上添花"，不是第一版必需。

## 六、平板固定：托边 + 压边（不用磁吸）

磁吸在这个场景不成立：面板倾 20° → **重力沿斜面下滑**，磁吸只有法向力，
抗滑靠摩擦；加上车在跑，会滑落。改纯机械：

```
        压边（顶部，包住平板 3mm，弹性臂）
      ┌──────────────────────────┐
      │                          │
      │         平板              │  200.2 × 120.3
      │                          │
      └──────────────────────────┘
       ↑ 托边（底部，承重 + 定位，深 5mm / 高 8mm）
```

| 部位 | 做法 |
|------|------|
| **底部托边** | 深 5mm、高 8mm，承全部重量 + 定位 |
| **顶部压边** | 包住 3mm，带弹性臂，上沿外扳即可取放 |
| **左右限位** | 两侧各 2mm 挡边 |
| **散热** | 背板开**阵列圆孔**，平板背面不闷 |

> ⚠ **材料必须 PETG**（或 ASA/ABS）。车内暴晒 60-70°C，**纯 PLA 会软化**，支架塌了砸平板。

## 七、两处安装要点

### 7.1 水槽下方柜体正面

| 项 | 做法 |
|----|------|
| 位置 | 柜体正面中下部，支架宽 214mm（柜面宽 600-700mm，**占不到 1/3** ✅） |
| 固定 | 4× M4 木螺丝 → 面板厚 **≥15mm**；薄板**内侧加木条背衬** |
| 找平 | 支架底部贴泡棉条（面板不平会晃/异响） |
| 走线 | USB 从支架底部 φ8 圆角孔进，**固定在支架上**（不动，无疲劳） |
| 供电 | 12V→5V 3A 降压模块放柜内，**高于盆底排水口**、防溅 |
| 按钮 | 支架**下方留 2-4 颗物理按钮**（排水/水泵/主灯/排气扇） |

> ⚠ **安装高度待确认**：你说面板底沿离地 **40-50cm**，但支架外廓高 140mm
> （若上沿贴台面下沿 850mm，底沿应约 710mm）。**两个数字对不上**，
> 需现场确认支架装在柜面什么高度——这直接决定倾角与视角。

### 7.2 额头柜下沿

| 项 | 做法 |
|----|------|
| 位置 | **贴额头柜底下沿，垂直向下延伸**（支架高 140mm） |
| 净空 | 需确认**柜底到仪表台/挡风玻璃的净空 ≥140mm**，否则平板顶到仪表台 |
| 固定 | 支架顶面用 4× M4 螺丝**从下往上**固定在柜底 |
| 走线 | 沿柜内走线到 N100/12V，柜底开 φ8 进线孔 |
| 视角 | 此处**眼位更低**（坐姿），倾角需**重新算**，不能照搬水槽前的 20° |

> ⚠ 额头顶的安装高度与坐姿视角有关，**建议做一个纸样先比划**再打印。

### 7.3 吊顶（顶棚）悬吊

| 项 | 做法 |
|----|------|
| 位置 | 吊顶（顶棚）板下方，平板**向下悬吊**，坐姿仰视 |
| 接口 | **利用已预埋的 1/4" 螺纹**（相机螺孔）——直接拧球头/关节 |
| 角度 | **必须可调**（14-48°，见 §四之二）→ 球头带锁紧，或齿盘关节 |
| 支架壳 | 用 [tablet-mount.scad](tablet-mount.scad) `mod="ceiling"` + `add_mount=true` |
| 螺纹座 | ⚠ 若预埋的是**木板直接攻丝**，悬吊 350g + 颠簸会**滑牙拔脱**——**须换金属 T 型螺母/预埋螺母** |
| 走线 | 顶棚内走线到 N100/12V；电源线**从支架上方进**（悬吊时自然下垂） |
| 净空 | 平板底沿离地需 **高于坐姿头顶**（约 125cm + 余量），避免起身撞头 |
| 收放 | 建议**可上翻收纳贴顶**或**可整体拧下**，不用时收起 |

> ⚠ **两个关键风险**：① 球头摩擦锁紧 → 颠簸下垂，必须带锁紧或齿盘；
> ② 1/4 螺母若只是木板攻丝 → 悬吊受力与壁挂不同（拉力+恒定弯矩），**必须金属预埋件**。

### 7.4 吊顶收纳（定稿：**可整体取下 + 挂墙钩**）

**决定**：做成**可整体旋下**，不用时挂到顶棚旁的钩上。

```
工作态                                收纳态
   顶棚 ────────┐                    顶棚 ────┬──────┬────┐
                │ 底座(1/4母)                │底座   │钩  │钩  │
              ╔═╧═╗                        (球头留)  └┬───┘
              ║球头║                                  │
              ╚═╤═╝                              ┌───┴───┐
            ┌───┴───┐                            │ 平板壳 │ ← 挂起贴顶
            │ 平板壳 │                             └───────┘
            └───────┘
            屏幕朝下前（可调 14-48°）
```

**为什么选"旋下 + 挂"而不是"上翻铰链"**：

| 方案 | 角度自由度 | 结构 | 适合 |
|------|-----------|------|------|
| 上翻铰链 + 卡扣 | 铰链本身不给倾角，**还要再加第二个关节** | 承重铰链 + 抗颠簸卡扣，复杂 | 每天翻来翻去的高频场景 |
| **旋下 + 挂墙钩** ✅ | **保留 1/4 球头全部自由度（14-48°）** | **一个挂槽 + 两个 L 型钩** | **驻车才用、平时收着**（本场景） |

> 关键洞察：**既然已经有球头可调角，"收纳"就不必再做一个铰链**——
> 直接整体取下挂旁边即可。结构更简单，且**不牺牲角度自由度**。

**收纳态几何**：平板上翻贴顶后从顶棚凸出约 **26mm（2.6cm）**（支架厚 16 + 底座/钩 10），
几乎齐平，不影响头部空间。

**两种挂法（推荐 A）**：

| | A. 挂槽 + L 型钩（**推荐**） | B. 磁吸位 |
|---|---|---|
| 做法 | 壳背面上方做燕尾挂槽（脚本 `stow="hook"`），顶棚打 2 个 L 型钩 | 顶棚贴铁片座，壳背面贴磁铁 |
| 优点 | **机械咬合，颠簸不脱** | 一贴就好，最简 |
| 缺点 | 要对准钩子 | 车内颠簸可能移位 |
| 备注 | 脚本已生成 `hook_slot()` 与 `ceiling_hook()` | — |

> ⚠ **挂槽位置**：中心偏上 **38mm**（避开 1/4 螺母座，实测不干涉）。
> **注意**：磁吸在**工作态**不可靠（前面论证过），但**收纳态是静态贴顶，磁吸反而合适**
> ——两种状态的可靠性要求不同。

**额外好处**：平板壳能单独取下，**契合"夏天带走"的想法**（整台拧下即可）。
