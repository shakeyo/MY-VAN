# ESP32 485 网关

## 架构

ESP32 运行 ESPHome 固件，作为 Home Assistant 的无线节点和 485 总线网关，**不是 HA 主机**。负责将 HA 指令转换为 485 总线信号，并采集总线设备状态回传 HA。

```
HA (N100) ← WiFi → ESP32 (ESPHome) ← UART → MAX485 ← RS485 → 总线设备
```

## 485 总线规范

- **拓扑**: 手拉手串联，**严禁星型或分支**
- **终端电阻**: 总线首尾 A/B 之间并联 120Ω 0.5W
- **屏蔽层**: 单端接地（仅 ESP32/主控端接地，末端悬空）
- **波特率**: 38400（模块出厂默认，地址 1~255 可设）
- **强弱电分离**: 485 信号线与 12V 负载供电线间距 ≥15cm，禁止同管走线

## ESP32-S3 ↔ MAX3485 接线

MAX3485 是 3.3V 收发器，与 S3 电平完全匹配，RO/DI 直连无需分压。

| ESP32-S3 | MAX3485 | 说明 |
|-------|--------|------|
| 3V3 | VCC | 3.3V 供电，严禁接 5V |
| GND | GND | 共地（必须单点共地） |
| GPIO15 (TX) | DI | 发送 |
| GPIO16 (RX) | RO | 接收 |
| GPIO5 | DE + RE（并接） | 高=发送、低=接收（modbus flow_control_pin 自动切换） |

## 供电

- 车载稳压模块：12V/24V 转 5V 3A
- 输入端并联 1000μF 电解电容 + 0.1μF 瓷片电容，抑制车载电压波动

## 焊接要求

- 焊点饱满，无虚焊、无连锡
- 所有地线统一共地，单点汇聚接地，杜绝多点接地环流
- 信号线套热缩管绝缘
