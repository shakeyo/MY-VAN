# ESP32 485 网关

> 全系统位置见 [smart-architecture.svg](../diagrams/smart-architecture.svg)（三级架构总图）；总线物理拓扑见 [04-power-system/485-bus.svg](../../04-power-system/diagrams/485-bus.svg)。

## 架构

ESP32 运行 ESPHome 固件，作为 Home Assistant 的无线节点和 485 总线网关，**不是 HA 主机**。负责将 HA 指令转换为 485 总线信号，并采集总线设备状态回传 HA。

```
HA (N100) ← WiFi → ESP32 (ESPHome) ← UART → MAX3485 ← RS485 → 总线设备
```

## 485 总线规范

- **拓扑**: 手拉手串联，**严禁星型或分支**
- **终端电阻**: 总线首尾 A/B 之间并联 120Ω 0.5W（末端当前在**中门 16DO**端；接床头模块后移至床头端）
- **屏蔽层**: 单端接地（仅 ESP32/主控端接地，末端悬空）
- **波特率**: **全车终局 9600 8N1（整车统一定稿）** —— MPPT（易科 Fcu）最高只支持 9600，故全车统一降速（规划源 [energy/mppt-protocol.md §二](../energy/mppt-protocol.md)）
  - ⚠ **当前固件仍为 38400**（模块出厂默认，桌面联调阶段）：MPPT 上车前必须改为 9600（FC06 写 0033H=1，操作步骤见 [build-guide.md 阶段 4.7](build-guide.md)），改模块的同时把固件 4 处 `baud_rate` 一起改掉
  - ⚠ 波特率代码各家不同：**MPPT 的 9600 = 代码 4**，**继电器模块的 9600 = 代码 1**，设置时勿混
- **地址**: 继电器模块 1~3（额头/中8/中4）+ **5（中门 16DO，全部 LED）**；能源设备 0x10（MPPT），485 传感器建议 0x20 起。库仑计 TF03K **不在本总线**（19200 独立 UART，见 energy/）。0x04 原为车尾模块预留，**该模块已取消**（倒车灯并进 中8.Y7），可留作未来设备
- **总线末端**: 当前最末端为**中门 16DO**（中门柜内）；接入床头模块后末端移到床头端，120Ω 随之移动
- **强弱电分离**: 485 信号线与 12V 负载供电线间距 ≥15cm，禁止同管走线

## 模块清单

| 地址 | 模块 | 位置 | 通道 | 职责 |
|------|------|------|------|------|
| 0x01 | 额头 8 路 | 额头柜 | 8DI + 8DO | 驾驶室负载（射灯/户外灯/DSP/副驾扇）+ 读驾驶室面板键 |
| 0x02 | 中门 8 路 | 配电箱内 | 8DI + 8DO | **纯负载**（主灯/氛围/排气扇/泵/水阀/冰箱/倒车灯）+ 读入口/主控键 |
| 0x03 | 中门 4 路 | 中门柜内 | 4DI + 4DO | 4 路 DO 留未来负载；读主控键5-6 |
| **0x05** | **中门 16DO** | 中门柜内 | 16DO（无 DI） | **全部 LED**（12 现用 + 4 预留），一个 485 地址 = 一个设备 |

> **LED 集中原则**：配电箱空间只有 4+8，DO 全留给稀缺的功率负载（藏墙不拆）；
> LED 是小电流指示，全部集中到中门柜的 16DO。负载 `on_state` 调 `relay-mid-16do.yaml` 的
> `led_*` 脚本同步驱动 LED，单一真源，避免两处各写一份。

## ESP32-S3 ↔ MAX3485 接线

MAX3485 是 3.3V 收发器，与 S3 电平完全匹配，RO/DI 直连无需分压。

| ESP32-S3 | MAX3485 | 说明 |
|-------|--------|------|
| 3V3 | VCC | 3.3V 供电，严禁接 5V |
| GND | GND | 共地（必须单点共地） |
| GPIO15 (TX) | DI | 发送 |
| GPIO16 (RX) | RO | 接收 |
| GPIO17 | DE + RE（并接） | 高=发送、低=接收（**由固件 rs485.yaml 手动切换**，未用 modbus flow_control_pin） |

## 固件架构

单 ESP32-S3 集中编译，packages 组装（详表见 [esphome/README.md](esphome/README.md)）。

- **写帧公共件 `rs485.yaml`**：`rs485_write` 参数化脚本统一处理
  `DE置1 → 1ms → uart.write → flush → DE置0 → 10ms`；通道动作只写一条帧，不再复制时序代码
- **按键 = 模块主动上传驱动**：上电写 FC06 `0031H=1` 开启，模块输入变化即发
  `<地址> 04 <字节数N> <N字节位图> <CRC>`；固件 100ms 读缓冲解析，**零轮询**
  - 位图字节数按模块自适应（中8=2、中4 可能=1），按帧内 `N` 算帧长 `3+N+2` 后验 CRC
- **LED = 16DO 集中驱动**：负载 `on_state` → `relay-mid-16do.yaml` 的 `led_*` 脚本 → 16DO 对应线圈
- **自动化全在本地**：按键→继电器联动（场景/双控/离车）不依赖网络或 HA

## 供电

- S3 扩展底板：内置 12V（6~24V）→ 5V/3.3V 降压，直接吃车载 12V，S3 插板载母排
- MAX3485 从 S3 的 3V3 取电（3.3V 收发器，与 S3 电平完全匹配，RO/DI 直连无需分压）
- 12V 进线侧并联 1000μF 电解电容，抑制车载电压尖峰（可选）

## 焊接要求

- 焊点饱满，无虚焊、无连锡
- 所有地线统一共地，单点汇聚接地，杜绝多点接地环流
- 信号线套热缩管绝缘
