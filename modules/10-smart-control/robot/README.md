# 中控台机器人

DIY 桌面表情机器人，安装在中控台，作为全车系统的语音/表情/动作交互入口。

**架构定稿**：大脑在 N100（HA Assist 语音管线 + 表情渲染），机器人本体是无脑外设；ESP32 只做身体 I/O 桥（舵机/触摸/状态灯），不跑语音和视觉。

| 文件 | 内容 |
|------|------|
| [design.md](design.md) | 架构、功能规划、与全车系统的交互、待定项 |
| [bom.md](bom.md) | 材料清单（待选型） |

## 边界

- 机器人是**操作入口**，不是安全关键执行者——安全自动化仍在 ESPHome 网关，原则见 [n100-ha/design.md](../n100-ha/design.md)
- 机器人依赖 N100 7×24 常开（见 n100-ha 常开策略）
- 中控台安装位置与走线见 [07-cabinetry](../../07-cabinetry/)
