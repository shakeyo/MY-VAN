# 中控台机器人设计

> 状态：**架构定稿，选型待办**。桌面表情机器人，中控台安装，语音（HA Assist）+ 表情 + 动作控制全车。

## 定稿原则

1. **大脑在 N100**：语音识别/合成（HA Assist 管线）、表情动画渲染、决策全部在 N100；机器人本体是无脑外设，性能无上限
2. **ESP32 只做身体 I/O 桥**：舵机 PWM、触摸、状态灯；不跑语音、视觉、动画
3. **控制动作走 HA 服务调用**：机器人是操作入口之一，与手机/平板/车机 Dashboard 平级；安全关键自动化仍留在 ESPHome 边缘，机器人挂掉只丢交互不丢安全
4. **依赖 N100 常开**：机器人无本地智能，N100 关机即变摆设

## 架构

```
中控台机器人（本体）
├── 表情屏（HDMI/USB-C 驱动板 ← N100 渲染动画）
├── 麦克风阵列（USB → N100，openWakeWord 本地唤醒词）
├── 喇叭（USB/3.5mm → N100，TTS 回复）
└── ESP32 身体桥（USB-CDC 或 WiFi → HA）
    ├── 舵机 ×N：转头、手臂动作
    └── 触摸传感器 / 状态灯
```

## 功能规划

| 功能 | 说明 |
|------|------|
| 语音控制全车 | 唤醒词 → HA Assist 意图识别 → 控制实体（灯/门/能源/场景），回复经 TTS 播报 |
| 表情反馈状态 | 表情屏动画映射全车状态：待机/聆听/思考/说话/报警（低电量、漏水、离车未锁） |
| 动作反馈 | 转头朝向说话人（麦克风阵列定位，待定）、挥手/点头等情绪动作 |
| 主动播报 | HA 通知事件（低电量、待机断电、行程建议）→ 机器人主动语音+表情提醒 |
