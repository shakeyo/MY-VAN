# MPPT 485 协议备忘与功能规划（易科 Fcu）

> 协议来源：`../../04-power-system/attachments/MPTT.pdf`（Fcu 控制器远程通信协议 V1.2）。本文 = 协议速查 + 集成规划。总线改造操作步骤见 [../gateway/build-guide.md](../gateway/build-guide.md)。

## 一、协议备忘

### 1.1 通讯参数

| 项 | 值 |
|----|-----|
| 物理层 | RS485，主从异步多机，一总线最多 16 台 |
| 帧格式 | 地址 + 命令 + 数据 + CRC16，定长帧，8N1 |
| 波特率 | 1200 / 2400 / 4800 / **9600** 可设（代码 1/2/3/**4**，无 38400） |
| 地址 | 0x01~0xF0 可设（0x00 = 群控广播）；本车规划 **0x10** |
| 查询间隔 | **≥1s**（本车规划 10s 轮询） |
| 校验 | CRC16（Modbus 多项式），低字节在前 |

> ⚠️ 波特率代码与继电器模块（汇控）不同：**MPPT 的 9600 = 代码 4，继电器模块的 9600 = 代码 1**。

### 1.2 命令集

| 命令 | 方向 | 长度 | 用途 |
|------|------|------|------|
| 0xA2 | 查询 | 9 → 88/65/28 | 查询设置参数（控制码 01 全部 / 02 仅 MPPT / 03 仅控制器） |
| 0xA3 | 查询 | 9 → 63/38 | 查询实时数据（控制码 01 全量 / **02 仅 MPPT 38 字节，采用**） |
| 0xC0 | 控制 | 9 → 9 原样返回 | 远程操控 |
| 0xD0 | 设置 | 13 → 13 原样返回 | 参数设置；出错返回 0xEE 帧 |
| 0xDE | 设置 | 9 → 无返回 | 群控（0x00）设波特率 |
| 0xDF | 设置 | 13 → 13 原样返回 | 时钟设置（0x00 群控不返回） |

### 1.3 关键帧速查（地址 0x10，CRC 已算）

```
查询实时数据(A3/02):        0x10 0xA3 0x02 0x00 0x00 0x00 0x00 0x6B 0x92
查询设置参数(A2/02):        0x10 0xA2 0x02 0x00 0x00 0x00 0x00 0x6A 0x43
允许充电(C0/01):           0x10 0xC0 0x01 0x00 0x00 0x00 0x00 0x26 0x01
禁止充电(C0/02):           0x10 0xC0 0x02 0x00 0x00 0x00 0x00 0x62 0x01
远程开DC输出(C0/03):       0x10 0xC0 0x03 0x00 0x00 0x00 0x00 0x5F 0xC1
远程关DC输出(C0/04):       0x10 0xC0 0x04 0x00 0x00 0x00 0x00 0xEA 0x01
蜂鸣器消音(C0/05):         0x10 0xC0 0x05 0x00 0x00 0x00 0x00 0xD7 0xC1
设DC输出方式=远程控制:      0x10 0xD0 0x0C 0x00 0x00 0x00 0x04 0x00 0x00 0x00 0x00 0xF2 0x4D
设充电最大电流30.00A:       0x10 0xD0 0x25 0x00 0x00 0x0B 0xB8 0x00 0x00 0x00 0x00 0x51 0x7C
群控设波特率9600(广播):     0x00 0xDE 0x42 0x04 0x00 0x00 0x00 0x70 0x81
时钟同步(2026-08-17 12:00): 0x10 0xDF 0x26 0x08 0x17 0x12 0x00 0x00 0x01 0x00 0x00 0xE0 0xC9
```

### 1.4 实时数据解析（0xA3 控制码 0x02，返回 38 字节）

| 偏移 | 数据 | 缩放/说明 |
|------|------|-----------|
| 3 | 运行状态（告警位） | bit0 电池识别错误 / bit1 过放保护 / bit2 风扇故障 / bit3 过温 / bit4 DC输出短路 / bit5-7 温度传感器故障 |
| 4 | 充电状态位 | bit0 充电中 / bit1 均充 / bit2 MPPT跟踪 / bit3 浮充 / bit4 限流中 / bit5 降额中 / bit6 远程禁充 / bit7 PV过压 |
| 5 | 控制状态 | **bit0 充电输出继电器** 0=关 1=开；bit2 风扇 |
| 6-7 | PV 电压 | ÷10（1 位小数） |
| 8-9 | 电池电压 | ÷100（2 位小数） |
| 10-11 | 充电电流 | ÷100（2 位小数） |
| 12-13 | 内部温度 1 | ÷10（1 位小数）；值 >4096 为负温：-(值-4096)/10 |
| 16-17 | 外部温度 1 | 同上，= 电池温度 |
| 20-23 | 日发电量 | Wh，4 字节高字节在前，**0 点清零（依赖内部时钟）** |
| 24-27 | 总电量 | Wh，同上，累计不清零 |
| 28-29 | 额定功率 | W |
| 30-31 | 发电功率 | W |

### 1.5 参数设置数据位布局（0xD0，13 字节）

`[地址, 0xD0, 参数代码, 数据1, 数据2, 数据3, 数据4, 数据5~8, CRC]`

| 代码 | 参数 | 布局 |
|------|------|------|
| 0x0C | DC 输出控制方式 | 数据4：0=关闭 / 1=自动 / 2=时控 / 3=光控 / **4=远程控制** |
| 0x22 | 浮充电压 | 数据3高 数据4低，÷100 |
| 0x25 | **充电最大电流** | 数据3高 数据4低，÷100（本车可调 number） |
| 0x23/0x26 | 低压保护/低压恢复 | 同上 |
| 0x27/0x28 | 过压保护/恢复 | ÷10 |
| 0x29/0x2A | 光控开启/关闭 PV 电压 | 无小数 |
| 0x2B/0x2C | 光控延时开/关 | 秒 |
| 0x2D~0x30 | 时控 1/2 开/关时间 | 4 字节：时十位/时个位/分十位/分个位 |

出错返回：`[地址, 0xEE, 错误码, 原命令码, 原控制码, ...]`，错误码 01 当前状态不能完成 / 02 命令不识 / 03 参数不识 / 04 数据超范围。

### 1.6 待实测确认项

- **0xDF 年份格式**：文档示例「0x12 表示 2018 年」疑为笔误（应为 0x18），本文按后两位+2000 理解（2026=0x26）
- 星期字段编码（暂按 1=周一）
- 关闭 DC 输出后控制器待机电流、485 是否仍响应（见第四节测试清单）

## 二、总线集成

单总线 **9600**（全车统一降速，替代原 38400）：

| 设备 | 地址 | 波特率 | 备注 |
|------|------|--------|------|
| 额头 8 路 | 1 | 9600（代码 1） | 继电器模块 0033H=1 |
| 中8 8 路 | 2 | 9600 | 同上 |
| 中4 4 路 | 3 | 9600 | 同上（通电前写） |
| 车尾 4 路 | 4 | 9600 | 新购，装机时写 |
| **MPPT（易科 Fcu）** | **0x10** | **9600（代码 4）** | LCD 上设或用 0xDE 广播 |
| PZEM-017 | 0x11 | 9600（出厂默认） | 地址出厂 1，需改为 0x11 |

MPPT 轮询 10s 一次（协议要求 ≥1s）；响应必须 CRC + 帧长双校验后才采信。

## 三、功能规划

### 3.1 监控实体（0xA3 轮询）

| 实体 | 来源偏移 | 用途 |
|------|----------|------|
| SolarPV PV电压 | 6-7 | 太阳能输入状态 |
| SolarBat 电池电压 | 8-9 | 48V 电池电压 |
| SolarChg 充电电流 | 10-11 | 实时充电电流 |
| SolarPower 发电功率 | 30-31 | 待机断电判定依据 |
| SolarDay 日发电量 | 20-23 | 每日统计（0 点清零） |
| SolarTotal 总电量 | 24-27 | **HA 能源面板**（total_increasing） |
| SolarTemp 控制器温度 | 12-13 | 高温保护参考 |
| SolarBatTemp 电池温度 | 16-17 | **低温禁充判定** |
| SolarState 充电状态 | 4 | 文本：停充/均充/跟踪/浮充/限流中/降额中/远程禁充/PV过压 |
| SolarAlert 告警 | 3 | 文本：无/过温/风扇故障/过放保护/DC输出短路/温度传感器故障/电池识别错误 |

### 3.2 控制实体

| 实体 | 帧 | 说明 |
|------|-----|------|
| SolarCharge 充电输出 | 0xC0 03/04 | 充电主开关，待机断电执行器（需预设 0xD0/0x0C=4 远程控制） |
| SolarEnable 允许充电 | 0xC0 01/02 | 软禁充（低温禁充用，保持监控在线） |
| SolarLimit 充电限流 | 0xD0 0x25 | number 实体，0 ~ 硬件上限（上限读 0xA2 响应偏移 17-18） |

### 3.3 自动化（ESPHome 本地跑，不依赖 HA）

1. **待机断电**：发电功率 < 5W 持续 30 分钟 → 关充电输出（协议档）/断接触器（硬件档）。夜间、阴雨天消除控制器待机功耗。
2. **恢复充电**：
   - 协议档：控制器重上线（轮询有响应）且 PV 电压 > 电池电压 +5V → 开充电输出
   - 硬件档：每日 7:00 闭合接触器 → 10:30 复查发电功率，仍 < 5W 再断开（阴雨天回断）
3. **低温禁充**：电池温度 < 2°C → 0xC0/02 禁止充电；> 5°C → 0xC0/01 恢复（与待机断电解耦：低温时保持控制器在线只软禁充）。
4. **时钟同步**：NTP 校时后每日 0:05 发 0xDF 单控校时——日发电量 0 点清零依赖内部时钟。
5. **开机自检**：上电读一次 0xA2，日志打印电池类型/额定电压/电流上限/地址/波特率，防配置被误改。
6. **离线检测**：连续 3 次轮询无应答 → SolarAlert 显示「离线」。

## 四、待机断电双档方案

### 4.1 档位选择依据（桌面测试定档）

| 测试项 | 结论 → 档位 |
|--------|-------------|
| 关闭 DC 输出后，待机电流是否归零 | 归零 → 协议档；不归零 → 硬件档 |
| 关闭 DC 输出后 485 是否仍响应 | 不响应 = 控制器整体断电（协议档成立） |
| 完全断电后 PV 恢复，控制器能否自启且保持远程控制模式 | 能 → 协议档闭环；不能 → 硬件档 |

### 4.2 协议档（首选，零硬件成本）

预设 DC 输出控制方式 = 远程控制（0xD0/0x0C=4，掉电保存）。夜间判定发电功率 < 5W 持续 30 分钟 → 0xC0/04 关输出。控制器若由电池回路供电且输出断开即整体掉电，待机归零。晨间 PV 恢复 → 控制器自启 → ESP32 轮询到在线 + PV 电压 > 电池+5V → 0xC0/03 开输出。

### 4.3 硬件档（备选，需加料）

若关输出后控制器仍有独立供电路径（待机不归零）：DC 输出口与空气开关之间串 **63A/48V 直流接触器**（输出最大 40A 量级，留余量），线圈 12V 由 **额头.R6** 驱动（继电器触点带线圈，线圈两端并续流二极管）。断开后 MPPT 整体断电、485 失联 = 离线状态。恢复靠定时闭合 + 功率复查，不依赖 MPPT 在线。

> 空气开关保留，作手动检修断电用，不参与自动化。

## 五、ESPHome 结构

- 新增 `../gateway/esphome/mppt.yaml`（package）：10s 轮询 interval + 全部实体 + 上述自动化
- `base.yaml`：`on_uart_message` 加 0xA3/0xA2 响应分支（沿用 read_upload 驱动模式：全局变量 → publish_state）；uart 波特率 9600
- `prod.yaml`：挂载 mppt.yaml
- 待机断电/恢复/低温禁充逻辑放 ESPHome 本地自动化（scripts + interval），断网可用

## 六、实施顺序

1. **桌面协议验证**（USB-485 直连 MPPT，9600）：0xA3 查询 → 0xC0 允许/禁止 → 0xD0 设远程控制 → 关闭输出后测待机电流与 485 存活 → 定档位
2. **总线改造**：全车模块波特率 9600（操作步骤进 [../gateway/build-guide.md](../gateway/build-guide.md)）
3. **固件**：mppt.yaml 写好 → 上车验证监控数据
4. **自动化联调**：待机断电 → 恢复 → 低温禁充（冰箱温度计模拟）
5. **HA**：总电量进能源面板，实体上 Dashboard
