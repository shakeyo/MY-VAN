# 监控与音响

## 视觉监控

### 架构

AHD 摄像头 → Y 型转接线并联 → DVR 编码器 → RTSP 网络流 → N100 Frigate（AI 识别） → HA Dashboard

### 设备

- DVR 编码器：AHD → RTSP
- AHD 摄像头 ×4：1080P，行车/驻车/侧方/后方
- 原车摄像头信号通过 Y 型转接线并联接入

## 音响系统

### 架构

```
音源（N100 / 蓝牙 / 安卓车机）
    → Alpine R600 8路 DSP 功放
        ├── 前门 Alpine DM65C 两分频
        ├── 后门 Alpine DM65 同轴
        ├── Alpine PWE-S800 超薄低音炮
        └── 额头柜喇叭（见 07-cabinetry）
```

### 声场模式

通过 DSP 预设切换：
- **驾驶**: 前声场为主，导航/通话优先
- **影院**: 全车环绕，配合投影使用
- **派对**: 高音量低音增强，户外场景

### 与影音娱乐的关系

全车音响硬件由本模块统一管理。额头柜喇叭为前声场的一部分（由 Alpine DSP 驱动），物理安装由 [07-cabinetry](../../07-cabinetry/) 负责。娱乐场景（投影/显示器）的音频输入切换见 [11-entertainment](../../11-entertainment/)。
