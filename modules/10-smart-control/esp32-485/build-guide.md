# 施工指导：ESP32 485 网关

## 工具清单

| 工具 | 用途 |
|------|------|
| 万用表 | 电压测量、通断检测 |
| 电烙铁 + 焊锡 | ESP32 与 MAX485 焊接 |
| 热缩枪/打火机 | 绝缘防护 |
| 压线钳 | 端子压接 |
| 串口调试助手 | 485 通讯测试 |
| USB 数据线 | ESP32 烧录 |
| 稳压电源（10-28V 可调） | 模拟车载电压波动测试 |

## 单板调试

1. **ESP32 供电**: 接入 5V，测量 3.3V 引脚输出（3.25V~3.35V）
2. **MAX485**: 5V 供电，测量 A/B 空载电压差（正常 A 比 B 高 2~6V）
3. **电源滤波**: 5V 输入端并联 1000μF + 0.1μF 电容

## 485 总线组网

- 手拉手串联，禁止分支
- RVSP 2×0.5mm² 屏蔽双绞线
- 首尾各一个 120Ω 终端电阻
- 屏蔽层单端接地

## 整机联调

1. 串口调试助手检查 Modbus 数据无乱码、无丢包
2. 10V~28V 宽电压测试，系统无重启、无死机
3. 整机装入 ABS 防水盒，减震固定
