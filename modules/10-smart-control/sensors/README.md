# 传感器

温湿度、水位、门磁、漏水、OBD-II 车辆数据采集。**温湿度走 BLE**（纽扣电池类，经 ESP32 蓝牙代理），485 传感器总线并联接入，干接点传感器走继电器模块 DI 口，不占用 ESP32 GPIO。

## 四条接入路径

| 路径 | 传感器 | 说明 |
|------|--------|------|
| 485 总线（9600） | 水位 | 要可靠，装在水箱旁 |
| DI 干接点 | 门磁、漏水 | 本来就是干接点，零成本 |
| MQTT（车机中转） | OBD-II | 蓝牙→车机→MQTT |
| **BLE → ESP32 代理** | **温湿度** | 纽扣电池传感器，不挤 485 |

> **安全关键的温度另走 485**：低温禁充判定用 MPPT 的 `SolarBatTemp`，
> 不用 BLE 温湿度（纽扣电池没电是静默失效）。
