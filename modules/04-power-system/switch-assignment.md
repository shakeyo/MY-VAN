# 面板开关分配 & IO 通道分配

## 按钮规格

- **类型**: 自复位（不带自锁），常开 NO
- **单色 4 线**: 绿绿 = 开关触点（COM/NO），红 = LED 阳极，黑 = LED 阴极
- **双色 5 线**: 黄白 = 开关触点（NO/COM），红 = 共阳（+12V），黑 = 红LED 阴，绿 = 绿LED 阴
- **DI 常态**: 模块内部上拉，静态高电平，按压拉低
- **逻辑**: 短按/长按判定在 ESPhome 里做，按钮本身无状态
- **汇接**: 每面板开关 COM 共 GND、LED 阳极共 +12V，焊并后用端子压接

## 模块清单

| 模块 | 位置 | 通道数 | 阶段 | 干什么 |
|------|------|--------|------|--------|
| **驾驶室A/B** | 额头柜 | 4DI+4DO ×2（5A） | ✅ 已有 1 台 + 1 台待买 | 驾驶室 6 键 + 功率负载（**原「额头 8 路模块」未购买**） |
| **中门-8路** | 中门配电箱内 | 8 DI + 8 DO（10A） | 现在 | **纯负载**（主灯/氛围/排气扇/泵48V/水阀/冰箱/倒车灯+预留）+ 读入口/主控按键 |
| **中门-4路** | 中门配电箱内 | 4 DI + 4 DO（**5A**） | 现在 | 3 路低功率负载（泵线圈/水阀/后窗扇）+ **Y4 灯光模式逻辑LED**；DI 全空 |
| ~~中门-16DO~~ | 中门柜内 | 16 DO（5A，无DI） | **已到货 · 已退役备用**（决4） | ~~全部 LED~~ → LED 改负载侧直连 + 场景键逻辑 LED |

> **架构定稿（最终）**：配电箱 DO 优先给负载（稀缺，藏墙不拆）。
> - **车尾不设模块**：倒车灯负载并进中8，电源从中门拉线到车尾。
> - **上水泵 48V 切外部继电器线圈**（48V 动力侧由大继电器隔离），续流二极管 1N5408。
> - **每个开关配一颗 LED**：有负载的键 **LED 并到负载继电器 NO 输出**（负载侧直连）；
>   只有「无负载可并」的场景键（离车/驻车、灯光模式）用**空余 DO 做逻辑 LED**（中8.Y8 / 中4.Y4）。
> - **16DO 退役备用**：不再上总线、不再承担 LED（见 决4）。
> - 不上位机，ESPhome 在 ESP32 本地跑自动化。后期加 HA 只做 dashboard/远程/通知，**不承载安全关键自动化**（角色边界见 [10-smart-control/n100-ha/design.md](../10-smart-control/n100-ha/design.md)）。

**通道编号规则**：

| 写在表里的 | 意思 |
|-----------|------|
| `额头.R1` | 额头模块第 1 路继电器 |
| `额头.DI1` | 额头模块第 1 路数字量输入 |
| `中8.R1` | 中门 8 路模块第 1 路继电器 |
| `中8.DI1` | 中门 8 路模块第 1 路数字量输入 |
| `中4.R1` | 中门 4 路模块第 1 路继电器 |
| ~~`16DO.R1`~~ | ~~中门 16 路 DO 模块~~（已到货、**已退役备用**，决4） |

> **模块丝印对照**：中8 模块实物端子按 PLC 习惯标 **X/Y**——**X1-X8 = 数字量输入**（即本文 DI1-8），**Y1-Y8 = 继电器输出**（即本文 R1-R8）。接线/排查按丝印找端子，按本文名称对逻辑：如 中8.R1 = 丝印 **Y1**、中8.DI1 = 丝印 **X1**。每个 Y 是继电器干接点，**COM = 公共端（进电侧）**，**NO = 常开出线到负载**，**NC = 常闭（本设计不用，一律空着）**。每个 Y 有三口：NO / COM / NC。

### 决5：大功率负载统一「两级切换」分级

> 小继电器盒（中8/中4 的 DO，5/10A，端子最多压 6~8mm²）**天生扛不住 >10A 大负载**——线再粗也没用，是触点额定低。统一原则：

- **>10A 或 48V 大负载** → 模块 DO 只切「大继电器/接触器线圈」（mA级），大继电器切真正的动力线：
  - **电动踏板**（12V，启动 20~40A）→ 40A 车规继电器（**踏板收回信号见 决7**：中8.Y3 只做信号/带小继电器线圈，绝不直切这 40A）
  - **DSP + 低音炮**（12V，20~30A）→ 40A 车规继电器
  - **车头射灯 ×2**（12V，10~20A）→ 30~40A 车规继电器
  - **上水泵 48V**、**MPPT 待机** → 63A 接触器（已有）
- **≤10A 小负载** → 模块 DO 直接切（主灯/氛围/排气扇/水阀/户外灯/倒车灯）。
- **10A 临界（留观察）** → 冰箱、尾门灯用模块 DO 直切，峰值实测后再定是否升级。
- **常电大电流**（DCDC 降压器、点烟器口）→ 不用继电器，靠源头大保险保护。
- **大继电器「跟着负载就近装」**：粗动力线走最短路径到负载，只有 mA 级线圈控制线跨柜拉到 485 模块（呼应「粗线就近、细线远程」）。

### 决6：逆变器（5000W）控制方案 —— 继电器短接 RJ 口（2026-10-30）

**逆变器已购：5000W，48V→220V 纯正弦波，自带 RJ 口远程控制面板（类似电话线）。**

#### 控制方式：短接法，不走协议

实测可用**短接某两根线**实现开关。故采用：

```
逆变器 RJ 口  ──┬── 两根控制线 ──┬── 继电器「干接点/触点」
                │                  │
              面板口              线圈 ── 中门柜 485 模块 DO（mA 级）
```

- **为什么不用协议**：厂商私有协议有兼容风险、需抓包逆向；短接法**只看电气通断，可靠得多**。
  协议可留作后续优化（若拿到文档），但**短接是终局可靠方案**。
- **继电器就近装在逆变器旁**：只有**线圈控制线**（mA 级，细线）跨柜拉到中门柜；
  **RJ 口两根线极短**，不经长距离。

#### ⚠ 电气参数（必须先实测再选继电器）

RJ 面板口**尚未实测**，施工前必须用万用表确认三件事：

| 待测 | 怎么测 | 影响 |
|------|--------|------|
| 短接时是**无源干接点**还是**带电压** | 万用表 DC 档量两根线间电压 | 带电压 → 需注意极性与继电器触点额定 |
| 若有电压，**电压/电流多大** | 实测值 | 决定继电器触点规格（多数面板口 5~12V / 几十 mA） |
| 短接是**脉冲触发**还是**电平保持** | 短一下松开 vs 持续短接，看逆变器行为 | 脉冲 → 面板需用「点动」而非「保持」 |

> **实际适配**：不接原面板时，把 RJ 口两根线接到继电器 **COM/NO** 触点；
> 若原面板要保留并联使用，需确认并联后不会互相干扰（建议二选一，不要并接）。

#### ⚠ 5000W 的直流侧：116A，这是硬约束

```
5000W ÷ 0.9(效率) ÷ 48V ≈ 116A 持续放电
（51.2V 标称下约 108A；峰值/启动可到 200A+）
```

| 项 | 要求 | 理由 |
|----|------|------|
| **动力线径** | **≥25mm²，建议 35mm²** | 116A 按 3~5A/mm² 保守取值 |
| **保险** | 150~200A（直流断路器或 ANL） | 就近装在电池侧 |
| **安装位置** | **必须紧挨电池**，不得放中门柜 | 粗线每米成本高、压降大；"粗线就近"原则 |
| **BMS 持续放电能力** | ⚠ **需确认 JK BMS 额定持续电流** | 116A ≈ 0.53C @220Ah；须确认 BMS 支持（常见 200A/300A 版本） |
| **启动冲击** | 逆变器启动峰值约 2×额定 | 线径与保险按峰值校核 |

#### 状态回读

逆变器**没有状态回读**（短接法只给控制不给反馈）。面板上的"开/关"是
**乐观显示**（ESPHome `optimistic: true`），不代表真实状态。
若需真实反馈，后续可考虑从 RJ 口取 LED 指示灯信号，或走协议。

### 决7：电动踏板「睡眠模式自动收回」（2026-10-30 取代原「入口键4 物理兜底」）

> **背景变更**：原方案（2026-10 早）是「入口面板第 4 键 = 物理小开关，串在门碰信号线上，断开就掐掉踏板唯一触发源」。
> 该方案的痛点是**靠人工记得去拧**——人躺下了往往已经是睡前进卧室之后，谁也不会再起身去门口拧一下。
> **改为场景联动**：进入「睡眠模式」→ ESP32 自动发「收回」信号，不依赖人记得操作。

#### 触发条件（用户定稿 2026-10-30）

| 项 | 定稿 |
|----|------|
| **何时收回** | **只有「睡眠模式」**（离车/驻车模式**不收**，仍可正常上下车） |
| **收回时其余动作** | 主灯关 + 氛围灯开（与原「夜灯」档一致，不额外关风扇/氛围） |
| **离开睡眠模式** | 信号松开 → 踏板恢复正常联动（开门伸/关门缩） |

#### 场景档位命名变更

灯光场景循环第 3 档由「**夜灯**」改名「**睡眠模式**」（档位号不变，仍是 `light_scene == 2`）：

```
0 全关  →  1 明亮  →  2 睡眠模式  →  0 全关 …（驾驶室键6 / 额头.X6 循环）
```

- 手机面板场景卡显示「全关 / 明亮 / **睡眠**」（`web/index.html` 的 `SCENE_META.light`）。
- 不改档位数 → 不新增按键、不动 DI，纯粹是改名 + 挂一个动作。

#### 信号载体：中8.Y3（2026-10-30 决8 改到中门配电箱，就近踏板）

| 项 | 值 |
|----|-----|
| 通道 | **中8.Y3**（线圈 0x0002）—— 中门配电箱，离踏板最近 |
| 固件实体 | `[中8.Y3] 踏板收回`（`sw_step_retract`，`internal: true` 不上面板） |
| 帧 | 吸合 `01 05 00 04 FF 00 CD FB` / 释放 `01 05 00 04 00 00 8C 0B` |
| 为什么用中8.Y3 | 踏板在中门附近，拉到额头柜不现实（**就近原则**）；中8 的 Y3/Y4/Y5 空着，Y3 给踏板、**Y4/Y5 留给真正的大功率扩展**（10A 不浪费在 mA 信号上） |

> ⚠ **R5 不自带功率能力**，它是**干接点信号输出**：R5 触点只负责「带一只小型车规继电器的线圈」或「直接串/并到踏板信号线」，
> **48V/40A 的动力线绝不经 R5**（动力线接原车电瓶，本箱只出信号——见 §6.4）。

#### 物理接法：三种可能，实测后定档（⚠ 施工前必做）

踏板控制器的接口尚未实测。用万用表/试短接确认属于哪一种，再决定 R5 怎么接：

| 档 | 控制器行为 | R5 接法 | 固件动作 |
|----|-----------|---------|----------|
| **A. 脉冲短接** | 短接一对线一下就收回 | `R5.COM/NO` 并到那对控制线 | **吸合 1.5s → 释放**（当前固件即是） |
| **B. 保持短接** | 要持续短接才保持收回 | 同上 | 睡眠期间**一直吸合**，离开睡眠才释放（删掉 `step_retract_signal` 里的 `step_release` 一行） |
| **C. 切门碰信号线** | 断开后控制器收不到开门信号 | `R5.COM/NO` **串**在「门碰开关 → 控制器」之间 | 睡眠期间**断开**（即 R5 释放=断、吸合=通时需在固件里反相） |

> **判断方法**（断电前先测，接线上电前再验）：
> 1. 万用表 DC 档量那对疑似控制线：**有电压** → 多半是电平型（B）；**无电压** → 无源干接点（A 或 C）。
> 2. 用镊子/导线**短接一下再松开**：踏板动作一下 → **A（脉冲）**；短接期间才保持 → **B（保持）**。
> 3. 若短接无任何反应，改测「门碰开关 → 控制器」那段，断开它看踏板是否停止自动伸缩 → **C**。

#### 固件实现（已就绪，2026-10-30）

```yaml
# scenes.yaml → apply_light_scene
light_scene == 2（睡眠模式）→ 主灯关 + 氛围开 + script.execute: step_retract_signal
light_scene == 0 或 1        → script.execute: step_release

step_retract_signal（mode: restart）→ R5 吸合 → delay 1.5s → step_release   # A 档
step_release       → 若 R5 仍在吸合则释放
```

改动一处即可在 A/B 档之间切换：删/留 `step_retract_signal` 末尾那行 `- script.execute: step_release`。

#### 已知限制

- **无状态回读**：踏板控制器不回传位置，固件只知道「发过收回信号」，**不知道踏板是否真的收了**（乐观显示）。
- **睡眠模式下仍可能被门碰触发**：若走 A/B 档（只发收回信号，不断信号线），睡梦中有人开门仍会让踏板伸出。
  要**彻底禁止**睡眠期间伸缩 → 必须落 **C 档**（断开信号线），C 是 A/B 的**超集**，可两项并用（两只继电器或一只双组触点）。
- **重新上车**：离开睡眠模式即恢复联动，不需手动复位。

## LED 策略

> ⚠ **本节是历史记录（16DO 集中方案），已于 2026-10-30 被 [决4](#决416do-模块退役led-改为负载侧直连为主--2026-10-30-已落地) 取代。**
> 现行标准见决4 的「终局接线表」：有负载的键 → LED 并到负载继电器 NO（负载侧直连）；
> 场景键 → 中8.Y8（离车/驻车）/ 中4.Y4（灯光模式）逻辑 LED。下表仅保留作对照与复活参考。

**每个开关都配一颗 LED 状态指示**（远程+本地双控下，没 LED 根本不知道设备开没开）。

LED 全部走**中门 16DO 模块**（16 路 DO，5A，一个 485 地址）——ESPhome 软件把「负载 DO 动作」与「LED DO 动作」绑成同步：负载 Y 吸合时，软件同时驱动对应的 LED Y 吸合，灯亮 = 设备开。**LED 全集中在一个设备里，ESPhome 配一个 16 路开关实体，最简洁。**

> **场景键降单色**：离车/驻车、灯光模式这 2 个场景键的 LED 用**单色**（亮=进入模式，灭=正常），不用双色红绿——这样 12 个按钮 = 12 路 LED，16DO 用 12 留 4。

**接线（独立 Y 驱动 LED）**：

```
LED 阳极（共阳，红线）→ +12V 控+
LED 阴极 ── 电阻(裸LED串1-3.3kΩ) ──→ 16DO 对应 Y 的 COM
16DO 对应 Y 的 NO ──→ 模块 GND
```

> 即：独立 Y 的 COM/NO 当"吸地开关"用，Y 吸合 → LED 阴极经触点回 GND → 灯亮。LED 与负载继电器彻底分离：负载在中8/中4（配电箱），LED 全在 16DO（中门柜）。

## 六、12V 保险分配

### 中门 12V 保险盒（12 路箱，现用 6 路 + 新增 N100/路由，余 5 路预留）

| 保险位 | 负载 | 电流 | 合并逻辑 |
|--------|------|------|----------|
| F12-1 | 控制系统 + 485 + 电控水阀 + 车内锁 + 踏步 + **ESP32 + 面板LED**（控制组） | 10A | 全控制级小电流，ESP32/LED 均挂此路（16DO 已退役，不占保险） |
| F12-2 | 主灯 + 氛围灯 + 睡眠灯 | 10A | 灯全合，进模块时 COM 分线 |
| F12-3 | 后窗排气扇（4 小风扇） | 5A | 低功率，独立 |
| F12-4 | 冰箱 | 10A | 压缩机启动电流大，独立 |
| F12-5 | 点烟器 1 | 15A | 二排座椅后 |
| F12-6 | 点烟器 2 | 15A | 中门柜 |
| **F12-7** | **N100 + 路由器**（尾门台面） | **5A** | **算力/网络组，必须独立，不与控制组共保险** |

> F12-2 出一根 1.5mm² → 到模块处分叉 → R1.COM + R2.COM。继电器 COM 端不受保险保护的那段极短（几 cm），安全。

> **控制组 vs 算力组的边界（关键）**：
> - **F12-1 控制组**：ESP32、3 个在役继电器模块控制电（中8/中4/额头）、面板 LED 共阳、车内锁、踏步，全是 mA 级小电流，可合并一路。
> - **F12-7 算力组**：N100 是整机（12V 直供，启动尖峰 + 满载 2~3A），路由器也有一定功耗，**必须单独 5A 保险**，绝不与 F12-1 共保险——否则 N100 满载会拉低控制组电压 / 顶保险，连带失去全车控制。
> - 功率负载（F12-2~4、倒车灯）各管各，不与任何信号/算力串联。

| 项目 | 值 |
|------|-----|
| 倒车灯 | 中8.Y7 → 拉线到车尾，5A 保险 |
| 车尾其他设备 | 未来加则从倒车灯同一路或点烟器取，或 485 总线再挂模块 |

### N100 + 路由器供电（尾门台面 · 12V 直供）

N100（12V 直供）+ 路由器装在**尾门台面（显示器后）**，距中门配电柜最远。供电从**中门 12V 保险盒 F12-7（5A）**出，沿「中门→尾门」路径拉 12V 正负极对（与倒车灯线同一路径、可共线槽，但**电不共用**——倒车灯挂中8.Y7 触点、随灯断电，N100/路由是常电设备）。

| 项 | 值 |
|----|-----|
| 取电 | 中门 12V 保险盒 F12-7（5A 独立） |

## 七、面板线缆定义（中门柜汇总方案）

> **核心思路**：中门柜（16DO 所在处）作为**全车信号汇接中心**——所有 DI（来自中8/中4）与 LED 阴（来自 16DO）先在中门柜汇总到一个「总端子排」，再从汇总排分线到各面板。面板侧一根复合线直达中门柜，不跑配电箱。
> 优点：面板离中门柜近，走线最短；DI+DO 单一汇总点，理线最清爽；加面板/加按钮从汇总排直接出，零拆改。驾驶室面板走额头模块，另案处理，不在本方案内。

### 全车统一色序表（14 芯 · 唯一标准）

**所有面板复合线、DI 主干一律用 14P 线 + 14P 插头，芯位色序全车唯一**——同一个位号永远是同一种颜色、同一个含义。备线只需一种，插错位也能一眼对出。

| 位 | 色 | 含义（复合线） | 含义（DI 主干） |
|----|-----|--------------|----------------|
| 1 | 黑 | GND | GND |
| 2 | 红 | +12V | +12V |
| 3 | 白 | 键1 DI | DI1 |
| 4 | 黄 | 键2 DI | DI2 |
| 5 | 灰 | 键3 DI | DI3 |
| 6 | 淡绿 | 键4 DI | DI4 |
| 7 | 深绿 | 键5 DI | DI5 |
| 8 | 棕 | 键6 DI | DI6 |
| 9 | 蓝 | 键1 LED 阴 | DI7 |
| 10 | 黑白 | 键2 LED 阴 | DI8 |
| 11 | 粉 | 键3 LED 阴 | DI9 |
| 12 | 橙 | 键4 LED 阴 | DI10 |
| 13 | 红白 | 键5 LED 阴（预留） | DI11 |
| 14 | 紫 | 键6 LED 阴（预留） | DI12 |

> **规律**：位1-2 是公共电源（黑 GND / 红 +12V），位3-8 是 DI 段（白/黄/灰/淡绿/深绿/棕），位9-14 是 LED 段（蓝/黑白/粉/橙/红白/紫）。**面板复合线与 DI 主干共用同一套线色顺序**，只是同一根芯在线里的用途不同。

### 主干与面板线总览

| 线 | 从 → 到 | P 数 | 内容 | 跨距 |
|----|---------|------|------|------|
| **DI 汇总主干** | 配电箱(中8+中4) → 中门柜汇总排 | **14P** | 12路 DI + GND + 12V | 一根长线（柜间） |
| **入口复合线** | 中门柜汇总排 → 入口面板 | **14P** | GND + 12V + 4 DI + 4 LED阴 + 预留4 | 近（中门柜旁） |
| **主控复合线** | 中门柜汇总排 → 主控面板 | **14P** | GND + 12V + 6 DI + 6 LED阴 | 近（中门柜旁） |
| **16DO 阴极限** | 16DO.Y1-10 → 汇总排 | 就地并 | 10路 LED 阴直接并进汇总排 | 同柜，零长 |

> 全车（入口+主控）就这 **1 根 DI 主干 + 2 根面板复合线**，**全部 14P 统一**。线型统一 0.5mm² 多芯信号线（DI 干接点、LED 阴仅几 mA，无需粗线）。插头用 JST SM/XH 或 Deutsch DT，14P 物理防呆。

### 中门柜总端子排（汇接中心）

汇总排分三区，物理相邻、标签分色：

| 区 | 端子 | 内容 | 去向 |
|----|------|------|------|
| **DI 区** | DI1-8 | 中8.DI1-8（来自 DI 主干） | 面板复合线的 4/6 路 DI 芯 |
| | DI9-12 | 中4.DI1-4（来自 DI 主干） | 同上 |

## 十、485 总线拓扑

![485 总线拓扑](./diagrams/485-bus.svg)

```
ESP32 网关（额头柜，与额头模块同柜）
  └── 额头 8 路模块（额头柜）── 中8（中门配电箱）── 中4（配电箱）── 床头模块（床头，规划中）
      ↑ 首端（120Ω）                                    ↑ 当前末端（120Ω）   ↑ 接入后末端（120Ω 移到这）
```

> ⚠ **现状说明（2026-10-30）**：16DO 退役后，**当前总线末端 = 中4**，120Ω 终端电阻装在中4 端；
> 网关仍在**额头柜**（与额头模块同柜），所以首端 120Ω 在额头柜。此前「网关在中门柜、16DO 为末端」
> 的描述随 16DO 退役作废 —— 若网关最终按中门柜实装，则末端仍是中4，只是首端换柜，链顺序不变。

手拉手菊花链，模块间用双绞线（A/B）。**严禁星型、严禁首尾成环**。终端电阻只在**两个物理端点**各一个 120Ω。

> **链顺序（现行）**：`ESP32(额头柜·首端) → 额头 → 中8 → 中4(末端)`，床头模块接入后变成
> `… → 中4 → 床头(末端)`。不含 T 型分支、不闭合成环。
> 配电柜到中门柜的 485 段很短（约 30cm 量级），差分反射可忽略；但仍须 A 对 A、B 对 B 对绞。
> ⚠ 短段最容易图省事把 485 与 12V/面板线捆同束——**485 必须单飞**（RVSP 屏蔽双绞，与任何 12V/面板线间距 ≥15cm）。
> 供电：网关就地取额头柜「控+」；中8/中4 取配电箱控制区 12V；均挂 F12-1 控制组（见 §六）。

> **床头模块接入后（规划）**：最末端由中4 变为床头模块，**120Ω 终端电阻随之移到床头端**（中4 端的电阻拆除）。
> 床头模块必须接在中4 **之后**（总线末端方向），不能从中间引出。
>
> **车顶 485 主干（规划）**：床头距中门柜约 4m、走车顶，可用**单根 8 芯屏蔽网线**作 485 干线（A/B 一对 + 485-GND + 12V 电源对 + 备用对），屏蔽层**单端接地**（网关端），沿线模块就近取电。物理走线可绕车顶一圈，但**电气上必须是菊花链，不可闭合**。

## 十一、线缆接头规划（中门柜汇总方案）

信号线一律 0.5mm² 多股软线。**中门柜为汇接中心**：DI 从配电箱集中拉一根 14P 主干进汇总排，16DO 阴极限就地并进汇总排，面板各自一根复合线从汇总排出。

| 线缆 | 从 → 到 | 接头 | 芯数 | 用途 |
|------|---------|------|------|------|
| DI 汇总主干 | 配电箱(中8+中4) → 中门柜汇总排 | **14P** | 14 | 12路DI + GND + 12V（把中8.DI1-8、中4.DI1-4 集中搬到汇总排） |
| 入口复合线 | 中门柜汇总排 → 入口面板 | **14P** | 14用10 | GND + 12V + 4DI + 4LED阴，位13-14 预留 |
| 主控复合线 | 中门柜汇总排 → 主控面板 | **14P** | 14 | GND + 12V + 6DI + 6LED阴 |
| 16DO 阴极限 | 16DO.Y1-10 → 汇总排 | 就地并 | — | 10路 LED 阴并进汇总排 LED 区 |
| 驾驶室面板 | → 额头模块 | 直接接线 | — | 同在额头柜，另案处理，不设接头 |
