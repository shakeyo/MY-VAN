# 中门智能配电箱

## 一、系统边界与架构

| 区域 | 归属 | 说明 |
|------|------|------|
| 额头柜配电箱 | 独立系统 | 48V 降压供点烟口、原车鼓风机、DSP、低音炮、MPPT 等，与本箱无关 |
| 中门配电箱 | 本方案范围 | 48V 进线 → 48V 水泵 + DCDC 降压 → 12V 灯/风扇/冰箱/控制 |
| 踏步 | 功率接原车电瓶 | 本箱仅出干接点控制信号 |
| 车内锁 | 12V 供电 | 由本箱 12V 回路经继电器控制 |

## 二、48V 主配电方案

### 2.1 进线与总保护

| 项目 | 规格 | 接法 |
|------|------|------|
| 总进线 | 2×8AWG 硅胶线（并联） | 正极并联后压 OT8-8 铜鼻 → 总开关输入 |
| 总开关 | 48V DC 隔离开关，≥60A | 柜内最左上方，带明显断开点 |
| 总保险 | 60A 直流保险片/断路器 | 紧挨总开关，正极串联 |
| 总负极 | 2×8AWG 并联 → OT8-8 | 直接压 48V 负极汇流排 |

> 2×8AWG 并联载流约 80A，总保护 60A 留有余量。

### 2.2 48V 保险盒分配（建议 6 路或 12 路）

| 保险位 | 设备 | 电流 | 线径 | 负极回哪 |
|--------|------|------|------|----------|
| F48-1 | DCDC 降压模块输入 | 20A | 6mm² | DCDC 48V- → 48V 汇流排 |
| F48-2 | 上水泵主回路 | 15A | 2.5mm² | 水泵负极 → 48V 汇流排 |
| F48-3 | 放水泵主回路 | 15A | 2.5mm² | 水泵负极 → 48V 汇流排 |
| F48-4 | 48V 接触器线圈控制 | 5A | 1.0mm² | 线圈负极 → 48V 汇流排 |
| F48-5 | 备用 48V 输出 | 10A | 1.5mm² | — |
| F48-6 | 备用 48V 输出 | 10A | 1.5mm² | — |

**接线方式**：

- 保险盒总正极输入：6mm² 红线，OT6-6 压保险盒总螺丝
- 保险盒总负极：6mm² 黑线，OT6-6 压 48V 汇流排
- 各路输出：对应线径，OT 铜鼻直接压保险盒分路螺丝
- **大功率回路（F48-1/2/3）不走 UK 端子排**

### 4.2 48V 水泵控制详图（核心安全回路）

**主回路 - 大电流，铜鼻子直连：**

```
48V 保险盒 F48-2(15A) ──OT2.5-6──→ 接触器主触点 COM
接触器主触点 NO ──OT2.5-6──→ 水泵正极+
水泵负极- ──OT2.5-6──→ 48V 负极汇流排
```

**控制回路 - 小电流，模块驱动：**

```
48V+ ──F48-4(5A)──→ 模块 R9-COM
模块 R9-NO ──1.0mm²──→ 接触器线圈+
接触器线圈- ──1.0mm²──→ 48V 负极汇流排
```

**保护：**

续流二极管 1N5408 并联在线圈两端：

- 阴极(有环) → 线圈+
- 阳极 → 线圈-

### 4.3 踏步控制详图

本箱不供功率，只出干接点：

```
本箱 12V 侧：
F12-8(3A) → 小型 12V 继电器线圈+（或用模块 R8 直接驱动）
线圈- → 12V 汇流排

该继电器触点 COM/NO → 引出到 UK 端子排 TB-STEP-A/B
→ 接原车踏步控制线（需确认原车是"高电平触发"还是"短接触发"）
```

- 若原车踏步是"短接即动作"：用模块 R8 的干接点 COM/NO 直接短接原车控制线
- 若原车踏步是"12V 高电平触发"：用本箱 12V 继电器触点引出 12V 信号

### 4.5 12 芯线标准化

继电器模组与外部设备（开关面板、负载）之间采用 **12 芯 RVV/RVVP 线缆**统一连接。每根 12 芯线对应 **4 路继电器**，线序固定：

| 芯号 | 定义 | 线色 | 说明 |
|------|------|------|------|
| 1 | DI1 | 白 | 开关 1 输入 |
| 2 | DI2 | 灰 | 开关 2 输入 |
| 3 | DI3 | 紫 | 开关 3 输入 |
| 4 | DI4 | 绿 | 开关 4 输入 |
| 5 | OUT1 | 黄 | 输出 1（负载+灯） |
| 6 | OUT2 | 橙 | 输出 2（负载+灯） |
| 7 | OUT3 | 蓝 | 输出 3（负载+灯） |
| 8 | OUT4 | 棕 | 输出 4（负载+灯） |
| 9 | GND | 黑 | 公共地 |
| 10 | +12V | 红 | 模块供电 / 开关公共端 |
| 11~12 | 备用 | — | 预留扩展 |

**8 路模组映射为两根 12 芯线**：

| 电缆 | 对应继电器 | 覆盖按键 |
|------|-----------|----------|
| 电缆 A | R1~R4 | SW1~SW4（主灯、氛围灯、睡眠灯、排气扇 1） |
| 电缆 B | R5~R8 | SW5~SW8（排气扇 2、冰箱、车内锁、踏步） |

> R9/R10（48V 水泵控制）不走 12 芯线，单独接线。

**线缆选型**：
- 常规：RVV 12×0.5mm²
- 靠近干扰源（DCDC、逆变器）：RVVP 12×0.5mm²（屏蔽层单端接地）

### 4.6 单个按键接线详图（NPN 输出模块）

每个带灯按键涉及三个回路：**开关检测**、**LED 指示灯**、**负载驱动**。OUTx 同时驱动负载和按键 LED，保证灯与负载同步：

```
按键开关（自复位或自锁）：
  COM ──── GND（12 芯线 #9）
  NO  ──── DIx（12 芯线 #1~4）

按键 LED（内置于开关）：
  灯+ ──── +12V（12 芯线 #10）
  灯- ──── OUTx（12 芯线 #5~8）

负载（灯/风扇/锁等）：
  负载+ ──── +12V（经保险盒供电）
  负载- ──── OUTx（12 芯线 #5~8）
```

```
          ┌──────────────────────────────────┐
          │         12 芯线（至配电箱）        │
          │                                  │
  +12V ───┼──┬──────────── 按键LED+          │
          │  │                               │
  GND  ───┼──┼── 按键COM                     │
          │  │                               │
  DIx  ◀──┼──┼──────────── 按键NO            │
          │  │                               │
  OUTx ◀──┼──┴── 按键LED- ──── 负载-         │
          │                                  │
  +12V ───┼──────────── 负载+                │
          └──────────────────────────────────┘
```

> **关键**：OUTx 一拖二（按键 LED 负极 + 负载负极），NPN 输出导通时 LED 与负载同时动作，实现按钮灯同步。

### 4.7 48V 水泵控制（R9/R10）

水泵控制不走 12 芯线，继电器 COM 端直接接 48V 经保险盒供电，NO 端驱动接触器线圈。详见 [4.2 48V 水泵控制详图](#42-48v-水泵控制详图核心安全回路)。

## 六、UK 端子排分区与色标方案

### 6.1 端子色标规范

不同电压等级使用 UK 端子统一颜色标记，目视即可区分，防止误接：

| 电压 / 信号 | 端子颜色 | 线色 | 说明 |
|------------|---------|------|------|
| 48V+ | **红色** | 红 | 48V 正极，所有 48V 供电回路 |
| 48V- | **灰色** | 灰/黑 | 48V 负极汇流排 |
| 12V+ | **蓝色** | 蓝 | 12V 正极，保险盒输出及负载供电 |
| 12V- | **灰色** | 灰/黑 | 12V 负极汇总 |
| 信号线 | **绿色** | 绿/黄 | DI 输入、485 通讯、传感器 |
| 保护接地 | **黄绿色** | 黄绿 | 机壳接地、等电位连接 |

> **灰色端子**同时承载 48V- 和 12V-，因为两者通过 DCDC 内部连接或外部单点短接后为等电位，统一用灰色端子排集中管理。

### 6.2 隔板物理隔离

不同电压等级区域之间必须用 **UK 终端固定件（隔板/端板）** 分隔，确保相邻端子不会因松动触碰导致高压窜入低压回路：

```
[48V 区] │隔板│ [12V 区] │隔板│ [信号区] │隔板│ [485 通讯区]
  红色        │       蓝色/灰色       │      绿色        │       绿色
  灰色        │                       │                  │
```

**隔板选型**：UK 系列通用隔板（如 UK-6N 端板），厚度 1.5mm，卡入导轨即可。

### 6.3 单根 DIN 导轨布局

导轨长度约 50cm，从左到右排列：

```
┌──────────────────────────────────────────────────────────────────────┐
│ 红标 48V 区  │隔│  蓝/灰标 12V 区   │隔│  绿标 信号区   │隔│ 485 区 │
│              │  │                   │  │               │  │        │
│ 1 48V+ 进线  │板│ 1 +12V 总线       │板│ 1 DI1 (SW1)   │板│ A      │
│ 2 上水线圈+  │  │ 2 OUT1 (R1)       │  │ 2 DI2 (SW2)   │  │ B      │
│ 3 放水线圈+  │  │ 3 OUT2 (R2)       │  │ 3 DI3 (SW3)   │  │ GND    │
│ 4 线圈公共-  │  │ 4 OUT3 (R3)       │  │ 4 DI4 (SW4)   │  │        │
│ 5 48V- 汇流  │  │ 5 OUT4 (R4)       │  │ 5 DI5 (SW5)   │  │        │
│              │  │ 6 OUT5 (R5)       │  │ 6 DI6 (SW6)   │  │        │
│              │  │ 7 OUT6 (R6)       │  │ 7 DI7 (SW7)   │  │        │
│              │  │ 8 OUT7 (R7)       │  │ 8 DI8 (SW8)   │  │        │
│              │  │ 9 OUT8 (R8)       │  │ 9 备用         │  │        │
│              │  │10 灯负汇总        │  │10 备用         │  │        │
│              │  │11 扇负汇总        │  │               │  │        │
│              │  │12 12V- 汇流       │  │               │  │        │
└──────────────────────────────────────────────────────────────────────┘
```

> **12V 区**：蓝色端子走正极，灰色端子走负极，同区混排但端子颜色区分即可。隔板主要隔离 **48V 与 12V** 两个电压等级。

### 6.4 端子排与 12 芯线对接

两根 12 芯线（电缆 A: R1~R4，电缆 B: R5~R8）在端子排上的落点：

```
电缆 A（SW1~SW4）：
  12 芯线 ──→ 信号区端子 DI1~DI4
  12 芯线 ──→ 12V 区端子 OUT1~OUT4
  12 芯线 ──→ 12V 区端子 +12V / GND

电缆 B（SW5~SW8）：
  12 芯线 ──→ 信号区端子 DI5~DI8
  12 芯线 ──→ 12V 区端子 OUT5~OUT8
  12 芯线 ──→ 12V 区端子 +12V / GND
```

> **防呆铁律**：48V 插头与 12V 插头绝不能用同系列同色。48V 用 Anderson SB50 蓝色，12V 用 Deutsch DT，一眼区分。

## 八、施工与验收规范

1. **先测 DCDC 隔离性**：万用表通断档测 48V- 与 12V-，确认后再决定汇流排是否短接
2. **先装骨架后接线**：底板 → 导轨/汇流排 → 保险盒 → 模块 → 端子排
3. **先接内部跳线**：保险盒 → 模块 COM；模块 NO → 输出端子排；端子排 → 汇流排
4. **再接外部线束**：每束带插头和标签
5. **大功率压接必查**：OT 铜鼻用液压钳压，包热缩管，螺丝打扭矩
6. **逐路通电**：先 48V 总进线 → 测 DCDC 输出 → 12V 控制模块 → 灯 → 风扇 → 水泵（最后）
7. **水泵试车前**：确认接触器线圈电压、续流二极管方向、主回路相序
8. **箱体就位后再接线**：先固定箱体到支架，后做内部跳线
