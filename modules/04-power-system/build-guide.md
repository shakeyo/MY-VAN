# 施工指南：电力系统（整车主线）

> 本文是电力系统的**执行手册**：按 6 个阶段顺序施工，每阶段有入口条件、动作、验收点。
> "为什么这样做"见 [design.md](design.md)；箱内细节见 [design-distribution-box.md](design-distribution-box.md)；按键/线色对照见 [switch-assignment.md](switch-assignment.md)。
>
> **三条红线（任何时候）**：
> 1. 动功率线前先断电（拔保险或分总开关），确认后再动手。
> 2. 48V 插头（Anderson SB50 蓝）与 12V 插头（Deutsch 黑）绝不混插。
> 3. 顺序不可改：电源 → 保险盒 → 继电器 COM → NO → 端子排 → 负载。

## 0. 准备（开工前 1-2 周）

**采购**：照 [bom.md](bom.md) 照单采购，工具必买：液压压线钳（OT 铜鼻）、万用表、剥线钳、压线钳（冷压端子）、焊台、热风枪、标签打印机/防水标签。

**家里预制（最重要的省时项）**——负载线都是"模块/保险 → 端子排 → 负载"，负载位置固定、线长可提前确定，全部在家做好，车上只插端子排：

1. 按 [switch-assignment.md §八](switch-assignment.md#八、中门配电箱端子排布局) 量各负载线长（留 5-10cm 余量），裁线、剥线、压冷压端子并压紧
2. 该并的先并好，套热缩管 + 贴标签：
   - 氛围灯/睡眠灯 4 路：中8.R2.NO 并 4 路出线（位 5-8）
   - R1/R2 COM 分叉：F12-2 的 1.5mm² 分叉到 R1.COM + R2.COM
   - 双控泵 LED：14芯A 芯11 粉 + 14芯B 芯12 橙 并好，出单线到 中8.OUT6
3. 每个负载 2P 正负各一芯，正进红色区对应位、负进黑色桥
4. 14 芯线两端压 14P 插头（入口=黑壳+蓝标，主控=黑壳+绿标），键5-6 压 8P 短跳线
5. 按钮侧：单色/双色按钮线按 [switch-assignment.md §七](switch-assignment.md#七、14-芯线缆定义) 压入面板 EDK 插座，焊并点：入口 2 个（COM、阳极）、主控 4 个（COM①②、阳极①②）

**验收（出口条件）**：
- [ ] 每根线**两端**都有标签（`12V-主灯+` 格式）
- [ ] 端子排、保险盒、继电器、铜鼻等全部就位清点
- [ ] 14P/8P 插头芯色顺序与 [14core-cable.svg](./diagrams/14core-cable.svg) 一致

**配图**：[power-architecture.svg](./diagrams/power-architecture.svg)（开工前通读整车电流走向）

## 1. 电池与总保护

**入口**：车体地板/锚固点已按 [01-vehicle-layout](../01-vehicle-layout/) 完成。

1. 安装 48V 磷酸铁锂电池组，锚固（防振 + 绝缘，不碰金属车身）
2. 电池侧就近装**源头熔断器 150A + 主断路器 125A**（正极串：电池+ → 熔断 → 主断）
3. 2×8AWG 硅胶线（并联）→ OT8-8 铜鼻 → 引向中门配电箱（顶部入箱）；总负 2×8AWG 并联同引
4. BMS 低温保护确认（低温禁止充电策略生效）

**验收**：
- [ ] 铜鼻液压压接 + 热缩，螺丝打扭矩，无裸露铜
- [ ] 绝缘检查：电池壳体/铜鼻与车体无接触
- [ ] 主断可正常分合，分断后有可见断开点

**配图**：[power-architecture.svg](./diagrams/power-architecture.svg) 左侧链路

## 2. 中门配电箱（核心，2-3 天）

**入口**：箱已用铝型材支架固定（[design-distribution-box.md §十三](design-distribution-box.md#十三、箱体安装支架-铝型材)），箱内器件已就位（按 [box-layout.svg](./diagrams/box-layout.svg) 核对位置：DCDC 左上、48V 保险右上、12V 保险中左、负极端子排中部、8 路模块右下导轨、端子排箱底）。

按 [design-distribution-box.md §十 施工步骤 1-10](design-distribution-box.md#十、施工步骤-按顺序执行) 顺序执行，此处给每步的**关键动作 + 验收点**：

| 步骤 | 关键动作 | 验收点 |
|------|----------|--------|
| 1 负极端子排 | 中部固定绝缘底座 + 桥接端子排；48V 保险盒负极 → 6mm² 黑线（OT）→ 桥接排 | 底座绝缘不碰箱体 |
| 2 负极回路 | 12V 保险盒负极短跳线、模块负、水表负全部回桥接排 | 每根负极线贴底走成 ┐└ 形 |
| 3 48V 正极主干 | 总开关（左上）→ 总保险 60A → 48V 保险盒输入+ | 开关→保险→分配，无跳接 |
| 4 降压器 | F48-1 → DCDC 输入；DCDC 输出 ≥10mm² → 12V 保险盒总正；先测 DCDC 是否隔离型（通断档测 48V- 对 12V-） | 周围 5cm 无线缆；非隔离型才允许共负 |
| 5 12V 分配 | 12V 保险盒 → 各支路（F12-1~6，见 [switch-assignment.md §六](switch-assignment.md#六、12v-保险分配)） | 每路保险值 = 负载电流 ×1.25~1.5 |
| 6 继电器功率回路 | 每路：保险盒输出+ → 继电器 COM → NO → 端子排正极位 | 继电器一一对应保险位，顺序正确 |
| 7 控制电源 | F12-1 → 2A 保险 → 控制区「控+」（并接 2-3 位）；控- → 桥接排 | 控制电源独立 2A，不与负载共保险 |
| 8 信号线 | 按钮 DI 线直进模块（不过端子排）；485 双绞单独走线槽，远离功率线 ≥15cm | 14 芯线入走线槽，槽口出线 |
| 9 负载出线 | 端子排正极区 → 各负载正；各负载负 → 负极区桥接位 | 与预制线束标签对位，正负不串位 |
| 10 整理标识 | 功率线分束（48V/12V 分开）；两端标签；保险盒/端子排逐位标签 | 中间空、线在四边和底板（见 §十一走线规则） |

**核心安全回路**（48V 水泵）单独照 [pump-48v.svg](./diagrams/pump-48v.svg) 施工，通电前 4 项核查（线圈电压/二极管方向/主回路相序/保险值）。

**验收（进阶段 3 前，必须全过）**：
- [ ] [design-distribution-box.md §十二安全检查清单](design-distribution-box.md#十二、安全检查清单) 11 项全勾
- [ ] **未通电**用万用表逐路测短路：任意两路正极位之间、正极位对箱体、负极端子排对箱体，均应无穷大
- [ ] 保险全部就位但**暂不拔插**，准备阶段 5 通电

**配图**：[box-layout.svg](./diagrams/box-layout.svg) · [terminal-block.svg](./diagrams/terminal-block.svg) · [pump-48v.svg](./diagrams/pump-48v.svg)

## 3. 面板与线缆

**入口**：阶段 2 完成。

1. 按钮侧核对：每颗按钮线色/触点/LED 极性按 [switch-assignment.md §七 面板侧接线](switch-assignment.md#七、14-芯线缆定义) 表对号（单色两绿线不分极性；双色黄/白不分极性）
2. 焊并点焊好（入口 2 个、主控 4 个）：拧线 → 焊锡 → 热缩 → 单线压入 EDK 端子
3. 14 芯线 → 14P 插头压接（芯序对照 [14core-cable.svg](./diagrams/14core-cable.svg)），8P 短跳线压接
4. 插头插入面板插座，面板装位
5. 双控上水泵：两颗按钮 LED 阴（14芯A 芯11 粉 + 14芯B 芯12 橙）在端子排「上水泵LED」位汇接后单线进 中8.OUT6

**验收**：
- [ ] 逐芯通断：14 芯每根一端一对，无错芯/短路
- [ ] 双色按钮：红阴/绿阴对应芯位正确（入口键4：绿→芯12、黑→芯13；主控键6：黑→8P-6、绿→8P-7）
- [ ] 明白"两个 COM"的区别（[button-wiring.svg](./diagrams/button-wiring.svg)）：按键 COM = GND 侧；继电器 COM = 正侧

**配图**：[14core-cable.svg](./diagrams/14core-cable.svg) · [button-wiring.svg](./diagrams/button-wiring.svg)

## 4. 485 总线 + ESP32

**入口**：阶段 3 完成。ESP32 网关制作见 [10-smart-control/gateway/build-guide.md](../10-smart-control/gateway/build-guide.md)。

1. 菊花链并线（**严禁星型**）：ESP32 → 额头模块 → 中8 → 中4 →（车尾模块，后期从末端并线）
2. 终端电阻 120Ω ×2：ESP32 端 + 最远端（当前是中4 端；装车尾模块时移到车尾端）
3. 屏蔽层单端接地；总线与功率线分槽，间距 ≥15cm
4. 核对每个模块地址（厂家软件改，重启生效）与 ESPhome 固件配置一致
5. **波特率**：本阶段桌面联调可用出厂 38400；**MPPT 上车前全车必须统一改 9600 8N1**（MPPT 最高只支持 9600），操作步骤与逐台帧见 [10-smart-control/gateway/build-guide.md 阶段 4.7](../10-smart-control/gateway/build-guide.md)

**验收**：
- [ ] A-B 间无短接（万用表电阻档，应约 2×120Ω ≈ 240Ω 以内量级）
- [ ] ESP32 上电后串口/日志可见各模块地址应答（桌面联调通过）

**配图**：[485-bus.svg](./diagrams/485-bus.svg)

## 5. 分阶段通电

**原则：一次只通一段，量完电压再通下一段。水泵永远最后。**

| 顺序 | 通电动作 | 测量 | 正常值 |
|------|----------|------|--------|
| ① | 合 48V 总开关（先不插模块保险） | 箱内 48V 保险盒输入端 | ≈ 电池电压（48V±） |
| ② | 确认 DCDC 通电 | DCDC 12V 输出端 | 13.5~14.5V（负载前空载略高） |
| ③ | 插 F12-1（控制电源 2A） | 控制区「控+」 | ≈12V |
| ④ | 插 F12-2（灯组）→ 逐键测试 | 按键 → 继电器吸合 → 灯亮/灭 | 按键与灯一一对应 |
| ⑤ | 插 F12-3（排气扇） | 按键 3 场景循环 | 4 小风扇按场景转 |
| ⑥ | 插 F12-4（冰箱） | 压缩机启动电流 | 启动后回落至稳态 |
| ⑦ | 插 F12-5/6（点烟器） | 插座电压 | ≈12V |
| ⑧ | **水泵最后**：核对 4 项（见 pump-48v.svg 核查框）后试车 | 接触器吸合声 + 泵运转 + 出水 | 单键双控都有效，ESPhome 状态同步 |

每一步若测量异常：**立即断电**，用未通电短路测试法排查（先查该路保险下游，再查上游），排除后再继续。

**整体验收**：[design-distribution-box.md §十二安全检查清单](design-distribution-box.md#十二、安全检查清单) 最后一项"逐路通电验证"完成。

## 6. 施工照片拍摄规范

配图分两类：**电路/布局图**（SVG，本模块 `diagrams/`，随设计更新维护）和**施工照片**（实物证据，放 `assets/photos/`）。照片按阶段拍，命名 `阶段-对象.png`，例如：

| 阶段 | 必拍 | 拍法 |
|------|------|------|
| 1 | 电池安装 + 主断/熔断 | 45° 斜拍，带锚固点和铜鼻，能看清保险额定值 |
| 2 | 箱内器件定位（空箱+器件未接线） | 正对箱面，和 box-layout.svg 同角度对照 |
| 2 | 负极端子排桥接 | 特写，短接片 + 6mm² 黑线 |
| 2 | 48V 进线铜鼻 | 特写：液压压接 + 热缩 + 扭矩 |
| 2 | 继电器 COM/NO 回路 | 带上保险盒一起拍，体现"先保险后继电器"顺序 |
| 2 | 箱内整理完成（关箱前） | 正对全貌：红线上、黑线下、中间空 |
| 3 | 面板背面焊并点 | 特写，COM/阳极焊并点各一张，标签可见 |
| 3 | 14P 插头压接 | 特写 14 芯色序，和 14core-cable.svg 对照 |
| 5 | 万用表读数 | 表笔 + 屏幕读数同框，背景是能认出测点的端子 |

**拍摄技巧**：
- 光线充足，避免逆光剪影；箱内用手电/台灯从侧上方打
- 关键部位用标签/箭头标出（拍完可撕掉，照片里有就行）
- 线束两端各拍一张（同一根线，证明两端标签一致）
- 每完成一个阶段立刻拍，不要攒到最后（最后一步的视角往往已经封死）

**嵌入文档**：照片放 `assets/photos/` 后，在对应文档用相对路径引用，如
`![箱内负极桥接](./assets/photos/2-配电箱-负极桥接.png)`。
README 底部的 AutoGallery 只收集 `assets/` 一级目录的图片（不含子目录），需要展示在模块首页的照片直接放 `assets/` 根目录。
