# 设计决策：用水系统

## 方案概述

独立水路系统，包含清水箱、灰水箱、水泵、管路及排水。进出水全部使用快接，年审可断开恢复空车。

## 系统架构

```
清水箱 → 过滤器 → 12V 自吸泵 → 管路 → 水龙头/水槽
                                          ↓
灰水箱 ← 排水管（快接） ← 地漏/水槽排水
```

## 关键决策

- **水箱材质**: 食品级 PE
- **水泵**: 12V 自吸泵
- **管路**: 食品级 PEX/PU 管
- **连接**: 全部快速接头，便于拆卸

## 用水点

| 点位 | 类型 | 模块 |

| 台面段水槽 | 冷水 | [07-cabinetry](../07-cabinetry/design-countertop.md) |

| 外置注水口 | 加水 | 车身左侧 |

## 排水

- 水槽排水 → 台面下方 → 灰水箱
- 淋浴地漏 → 快接软管 → 灰水箱
- 灰水箱可拆卸清倒
