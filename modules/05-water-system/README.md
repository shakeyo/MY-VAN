# 用水系统

全车统一的 **4 分净水器快接体系 + 双水源可切换**水路。**车底清水箱**（已装）与**车尾右侧柜下可移动副水箱**（新增）双水源，**两箱之间不输水**；用水靠泵前 **A/B** 阀选抽哪个箱。

> **🆕 加水自由切换 × 用水自由切换**：加水侧 **W1/W2** 选中门/尾门灌哪个箱；用水侧 **A/B** 选抽哪个箱。**全局总图见 [water-overview-2.svg](diagrams/water-overview-2.svg)**（含冷水主干、热水支路、尾门洗澡恒温阀、尾门/中门洗车口）。切换细节见 [design-tank-portability.md](design-tank-portability.md)。**叠加方案，不动已装的车底主箱与泵组，两箱之间不输水。**

**核心思路**：快接化 + 双水源 + 物理切换。全车只用一种管径（DM 4 分 / 外径 6.35 mm），切换只发生在泵的吸入侧，泵之后的管路与用水点完全共用；切换阀必须是手动球阀，不依赖电与软件。

## ⚙️ 双水源切换（本模块核心）

```
加水侧（独立支路，★不经过泵）        用水侧（泵前汇流，泵之后共用）
  中门注水口 ┐                      车底主箱 ─[A]─┐
              ├─ 三通J ─┬─[W1]→ 主箱               ├─ 三通Y → 粗滤 → 泵 → 止回阀 → 母管
  尾门注水口 ┘          └─[W2]→ 副箱   车尾副箱 ─[K1/K2]─[B]─┘

★ 同一组内两阀不同时开；跨组任意组合（可边灌主箱边用副箱）
★ 两箱之间不输水，换箱 = 手动切 A/B
```

**切换 SOP**（已打印贴在泵旁）：

```
1. 先关泵   2. 确认目标水源有水
3. 开目标路球阀 → 再关另一路球阀
4. 开泵，听声正常后用水   5. 用完关泵
```

> **铁律：泵运转过程中绝不切换阀门。**

## 🪣 车内取水桶

```
带盖桶 ─ 桶盖 φ13 穿板直通 ─ 30~50cm 食品级硅胶软管 ─ 4分快接公头 → 球阀 B
                              └ 桶内：304 配重沉头，离底 5~10 mm
桶盖另开 φ3~5 通气孔 + 防尘滤芯  ← 不开孔桶会被吸扁
```

**为什么这样设计**：4 分净水器 PE 管太硬，弯折半径大，直接往桶里插既插不到位、又会在桶口折弯憋死水流。所以**桶内用软管做柔性过渡（≤50 cm），桶外用硬管走快接**——每次取水你插拔的是一个快接头，而不是一根管子往桶里捅。

## ⚠️ 三条吸水侧保护（缺一不可）

| 保护 | 做法 | 不做的后果 |
|------|------|-----------|
| **前置粗滤** | 两条支路**各装一个**可拆洗不锈钢网粗滤 | 一颗砂粒卡死隔膜泵阀片 |
| **桶盖通气** | 桶盖开 φ3~5 通气孔 + 防尘滤芯 | 桶被负压吸扁甚至吸裂 |
| **干转保护**（待实现） | ESPhome：泵通电 15 秒水表无脉冲 → 断 Y4 + 告警 | 忘开阀干转几十秒即过热损坏 |

## 🔥 热水子系统（米家小厨宝 S1）

**核心决策：小厨宝不接混水阀。** S1 是储水式（7L/2000W），靠**自身温控**定温；接混水阀后出水被节流会导致罐内局部过热、温控提前跳，加上房车冷水压力本就不稳（泵启停、双水源切换），出水必然忽冷忽热。

**冷/热双母管**（每个用水点从母管**独立取一路，互不串接**）：

| 用水点 | 取用方式 |
|--------|----------|
| 台面水槽 | 冷水母管 + 热水母管**各取一路**，由自带龙头调温 |
| 尾门洗澡（车内浴盆 + 车外帐篷共用） | 冷/热母管各取一路 → **一个恒温混水阀** → 花洒（两处共用） |
| 中门洗车口 | **仅冷水**，从冷水母管独立取 → 球阀→单向阀→自锁快接 |
| 尾门洗车/冲脚口 | **仅冷水**直出，从冷水母管独立取 → 快拆头 |

> **只有淋浴需要调温。** 其余点位各取所需——要热水直接给小厨宝热水，要冷水直接给泵冷水。
>
> ⚠️ **严禁用水点串接**（把某点挂在他点下游）：他点一开关，水压水温立刻变，且极难排查。**例外**：车尾为单一用途出水口，冷热复用现有管即可，不另拉母管。

**两阀隔离**（实现"夏天断电断水甚至整机拆除"）：

```
阀 H 热水进水 → 关闭   断供水，可安全拆管
阀 O 热水出水 → 关闭   断出水，并隔离车尾热水预留
```

> ★ **夏季洗冷水不用开任何阀**：淋浴恒温阀「冷入口①」本来就直连冷水母管（主干），直接供冷水即可。
>
> ✅ **单边进水已实测：该阀不支持** → **阀 D 必装，且与热水支路同期做**。夏季开阀 D 把冷水灌进热水主干——**水槽热水口、恒温阀热入口、车尾预留全都有水**；不装则夏季水槽热水口直接断水、半个水槽报废。

**★ 尾门洗澡热水预留（本期铺管、不装阀）**：热水母管（阀 O 后）加 **DM 三通** → 铺管到车尾柜 → **封堵不进水**；车尾柜留 **150×150 mm 阀位**。冷水从主干取两路（恒温阀冷入口 + 尾门洗车口），各自独立。

> **尾门是三个口的落点**：洗澡（恒温阀花洒口，车内浴盆+车外帐篷共用）+ 洗车（冷水直出）+ 加水口。
>
> **恒温阀何时装**：等验证结果。恒温阀已采购，实测 4 项（水量衰减/压力扰动/小厨宝跟得上吗/关水再开）通过 → 装一个阀两处用；不通过 → 洗澡改手动混水阀。

**三个必备安全件**：热水侧**止回阀**（防倒灌）、**泄压阀**（排水必引至车外，绝不可堵死）、拆除前**先断电→泄压→再拆管**。

> ⚠️ 7L 在淋浴流量下约几十秒见底，需穿插用水；冬季必须排空罐内 7L 水，否则冻裂内胆。
