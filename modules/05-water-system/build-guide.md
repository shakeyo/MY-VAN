# 施工指导：用水系统

本文是 05 用水系统的施工主线。设计原理见 [design.md](design.md)，采购清单见 [bom.md](bom.md)。

> **🆕 车尾可移副箱 + 中门/尾门双加水口（加水/用水自由切换）**：见 [design-tank-portability.md](design-tank-portability.md)，施工见本文**阶段 1A**。**叠加内容**——阶段 1 的车底水箱（已装）与左侧外置注水口全部保留不动。

**施工顺序原则**：先做不会返工的（桶与软管辫预制、管路裁切），再做要上车固定的（水箱、泵），最后做要通电通水的（切换阀、试水试压）。**一次只通一段，量完再看下一段。**

## 阶段 0 · 预制（在室内完成，最省事）

这一步全部在家里的桌子上做完，上车只做安装。

### 0.1 预制"车内取水桶"

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 带盖食品级水桶洗净晾干 | 无残留异味 |
| 2 | 桶盖中心钻 **φ13 mm** 孔（先用小钻头定位，免崩边） | 孔圆整、无毛刺 |
| 3 | 装入 DM 4 分穿板直通：**外垫圈 → 穿盖 → 内垫圈 → 锁紧螺母** | 螺母拧紧后垫圈被压出轻微变形 |
| 4 | 硅胶软管（30~50 cm）一端套上穿板接头的内牙端，卡箍固定 | 用力拽不脱 |
| 5 | 硅胶软管另一端套 **304 配重沉头**，卡箍固定 | 沉头能自然垂到底 |
| 6 | 硅胶软管中段接 **DM 4 分快接公头**（或软管转 4 分快接的转接头） | 快接公头能顺畅插入母头并锁止 |
| 7 | 桶盖另钻 **φ3~5 mm 通气孔**，装防尘滤芯 | 通气顺畅（吹气不堵） |
| 8 | **注水静置测试**：桶装满水，倒置/侧放 10 分钟 | 桶盖穿孔处无渗漏 |

> **关键提醒**：4 分管外径是 **6.35 mm**，买件时认准 **DM 4 分快接**，别买成 1/2" 水暖件。

### 0.2 预制切换阀组

把两个球阀 + 一个三通在地面先连成一体，做一个"切换模块"，再整体上车：

```
        ┌──[球阀 A]── 车底水箱吸水管
三通 ───┤
        └──[球阀 B]── 车内水桶快接母头
   │
   └──→ 前置粗滤 → 泵吸入口
```

- 全部 DM 4 分快接插接，**插到底有"咔"感后再轻拉确认锁止**。
- 阀组固定在**泵附近的柜体内壁**，不要悬空吊在管上。

### 0.3 裁切 DM 管

- DM 4 分管用**专用切管器**切（不要用剪刀，切口会压扁导致漏）。
- **切口必须垂直、无椭圆、无毛刺**——这是 DM 快接漏水的头号原因。
- 管路走向拉直比划后再裁，**宁可长一点留余量，不可短**。

### 0.4 DM 管件配齐（按图点数）

| 管件 | 用在哪 | 数量 |
|------|--------|------|
| **DM 4 分三通** | ①切换阀组汇流 ②主管分冷/热 ③冷热各分用水点 | 4 |
| **DM 4 分弯头 90°** | 柜内全部转角（**每个转角都要装**） | 6 |
| **DM 4 分直通** | 断点续接、穿板前后接续 | 4 |
| **DM 4 分穿板直通** | 取水桶盖穿孔 | 1 |
| **DM 内外牙转换** | 接小厨宝进出水口、混水阀螺纹口 | 2 |

> ⚠️ **每个转角都必须装 DM 90° 弯头，严禁把 PE 管硬弯。** DM 4 分 PE 管弯曲半径大，硬弯会憋折导致水流衰减、管壁疲劳开裂——这是水路"用半年后水变小了"的常见原因。
>
> ⚠️ **小厨宝与恒温混水阀是螺纹口**，不能直接插 PE 管，必须用 **DM 内牙/外牙转换接头**过渡。

## 阶段 1A · 车尾可移副箱 + 双加水口（★ 增补施工）

> 设计依据：[design-tank-portability.md](design-tank-portability.md)｜全局总图：[diagrams/water-overview-2.svg](diagrams/water-overview-2.svg)｜切换细节图：[diagrams/water-portability.svg](diagrams/water-portability.svg)｜件量：[bom.md §十](bom.md#十、车尾可移副箱与双加水口（本方案新增）)

### 1A.1 先量的三个数（买件之前）

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | **车尾右侧柜下净空**：高/宽/深 + 柜板结构（能找到固定点的地方） | 画出草图，标出箱体能推进去的位置 |
| 2 | **副箱箱底 ↔ 泵（中门柜）的高差** | 确认自吸能拉上来（本方案不做箱间补给，与主箱高差无关） |
| 3 | **原 B 阀在哪、能不能直接改接**（design.md 已有 A/B 阀组） | 确认 B 路末端可改接快拆母头 K2 |

### 1A.2 副箱预制（室内）

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 箱体洗净，确认**食品级标识** | 无残留异味 |
| 2 | 箱底内壁装 **3/4" 螺纹底阀**（0.8~1.2 bar 常闭），螺纹涂食品级密封胶 | 注水静置 1 小时不渗 |
| 3 | 底阀外侧接 **柔性波纹管 30~50 cm** → 穿出箱体接 **K1 快拆自封公头**（bulkhead 型，内外垫圈 + 锁母） | 用力拽不脱；能顺畅插入母头并锁止 |
| 4 | 软管做成 **U 形低位**（先下后上），最低点就在出水口；箱底加 5~8 mm 楔形垫汇水 | 残水 ≤0.5 L（见 1A.5） |
| 5 | 箱内出水口加 **粗滤**（可拧下清洗） | 可单人拆洗 |
| 6 | 给水盖开 **φ3~5 通气孔 + 防尘滤芯** | 吹气不堵 |
| 7 | 箱侧上部开 **φ8 溢流口** → φ6 软管 + 防水透气帽，引到接水盘 | 模拟注满：溢流口先出水 |
| 8 | **底阀闭止测试**：装满水，K1 竖直朝下静置 10 分钟 | **不滴**（"快拆不漏"第一道） |
| 9 | **快拆联调**：插母头再拔出，两端各静置 5 分钟 | 两端均不滴；一人手按释放环即可单拔 |

### 1A.3 柜下格位安装（★ 不切钣金）

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 铝型材搭格位底座，贴 3 mm EPDM，固定点**只落在柜板上** | 手推不晃 |
| 2 | **限位：只能向外取出**，行车不可滑动 | 猛推三次位移 <5 mm；15 kg 满载急刹不倒 |
| 3 | 箱下留 **≥20 mm 通风** + 浅接水盘 | 漏一点也不积在柜底 |
| 4 | **K2 母头穿板固定在柜板**，从 K2 出管沿柜背走 | 无死弯，每 30~40 cm 管卡 |
| 5 | K2 → **B 阀** → 汇入泵前 **三通 Y**（与 A 路汇流） | 与 A 路汇流点一致；**不需要额外单向阀**（吸水侧是负压） |
| 6 | 标签：「**A = 抽主箱**」「**B = 抽副箱**」「拔箱前先关 B」+ 拔箱 SOP 卡 | 暗处可辨 |
| 7 | 原 B 路末端（车内水桶口）改接 K2，**不用封堵** | B 阀开关正常、无漏 |

> **碰接式（甲）怎么试**：把 K1 做成竖直朝下、K2 朝上，箱体落位即对接。先用**可微调浮动板（4 mm 腰孔 + 橡胶垫）**对准；对不准就退回软管跨接（乙）。**验收标准相同：单手、免工具、≤5 s、断开不滴。**

### 1A.4 双加水口安装（★ 独立，不进泵）

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 中门、尾门各钻注水口，装 **RV 自动回吸切断阀注水口** | 注口**高于所服务箱体最高水面**；带防尘盖 |
| 2 | 两个注口各接 4 分快接 → **三通 J 汇流** → 分 **W1（→主箱）/ W2（→副箱）** | 管路**与泵路无任何交点** |
| 3 | 灌水试：从中门接软管、开 W1 | 水进**车底主箱**，泵不转也进得去 |
| 4 | 同一口开 W2、关 W1 | 水进**副箱** |
| 5 | 换尾门注口重复 3~4 步 | 车尾口同样能灌两箱 |
| 6 | 灌满后**不关软管**停 2 分钟 | 两个注口都不溢、不漏、不互串 |
| 7 | 贴标签「W1 加主箱」「W2 加副箱」「W1/W2 不同时开」 | 清晰可辨 |

### 1A.5 副箱验收（打印贴柜内）

```
1. 残水测试：副箱灌 10 L → B 开 A 关 抽到空转 → 量副箱残水   目标 ≤0.5 L
2. 单手快拆：关 B → 按释放环 → 拔下 K1 → 关底阀        全程 <5 s，免工具
3. 断开不漏：拔出后 5 分钟，K1/K2 两端干纸巾擦拭        全干
4. 装回锁止：插回外拉一遍                              锁止有声、不松
5. 满载稳固：箱灌满，猛推三次                          位移 <5 mm
6. 加水切换：中门/尾门 × W1/W2 四种组合各试一遍         目标箱对、另一箱不进
7. 用水切换：A开B关 / A关B开 各抽一次                  各自出水连续、无气泡
8. 边灌边用：W1开 + A关 + B开（场景⑦）                 灌主箱同时副箱供全车
9. 快拆反复：连续插拔 20 次                            无滴漏、无卡涩
```

> **第 6、7 条是最容易接错的地方**（W/W 与 A/B 两组混接 → 灌错箱或抽不出水）。**必须逐一验证并贴标签。**
> 第 1 条若超标 → 改吸口位置/楔形垫，**不要习惯就好**。

## 阶段 4 · 试水（分步，不要一次全开）

### 4.1 只通水、不通电（静态检漏）

```
1. 车底水箱注水至 1/2
2. 开球阀 A，关球阀 B
3. 拿干纸巾逐个擦过每个快接接头与穿板接头
4. 静置 15 分钟，再摸一遍所有接头与接头下方
5. 有任何一处见湿 → 拔下重插（重插前必须重新切管口）
```

> **快接漏水的 90% 是切口不垂直或有毛刺。重插时一定要重切管口，不要"再往里捅一点"。**

### 4.2 单路试泵（车底水箱）

```
1. 确认球阀 A 开、球阀 B 关
2. 通电，按入口键3（或主控键4）开泵
3. 听泵声：连续平稳 = 正常；频繁启停 = 有漏气或压力开关设定问题
4. 打开水槽龙头，观察出水连续无气泡
5. 关龙头 → 泵应在数秒内自动停机（压力开关保压）
6. 关泵
```

### 4.3 切换试泵（车内水桶）—— 本方案的核心验证

```
1. 先关泵
2. 取水桶装满水，软管辫与快接公头就位
3. 快接公头插入球阀 B 的母头 → 听到"咔"→ 轻拉确认锁止
4. 开球阀 B → 再关球阀 A
5. 开泵，观察出水连续无气泡
   ★ 若出水断续带气泡 → 检查：桶盖通气孔是否堵、软管辫是否被吸扁、沉头是否露出水面
6. 关泵，拔下快接公头（自封式快接应自动止水，母头不滴水）
```

> **拔快接时母头若持续滴水**，说明买的是非自封型快接，需在球阀 B 与母头之间加装单向阀，或更换为带自封的母头。

### 4.4 干转验证（可选，验证保护逻辑）

若已实现 ESPhome 干转保护：关掉两个球阀后开泵，**15 秒内应自动断电并告警**。未实现前，此步**跳过**，且切换阀门时务必严守 SOP。

### 4.5 加水路验收（不动泵）★ 阶段 1A

```
1. 泵保持关闭（甚至断开 中8.Y4）
2. 中门注水口接软管 · W1 开 · W2 关 → 灌 10 L
   → 车底主箱水位上升，全程泵不转、管路无鼓胀、注口不漏
3. 仍从中门 · W1 关 · W2 开 → 再灌 5 L
   → 水进副箱，主箱水位不动
4. 换尾门注水口，重复第 2、3 步
   → 两种目标都能灌
5. 灌满后不关软管停 2 分钟，另一个注口保持关盖
   → 不溢、不渗、不互串
6. 关软管收口 → 轻摇车身模拟行车
   → 注口无渗水
```

> ★ **这一项证明两件事**：①**加水不需要泵**；②**W1/W2 没接反**（四种组合逐一验证）。
> 若某组灌注目标是错的箱，或第 2 步中泵被带转 → 管路接错（红线 22）。

### 4.6 用水切换验收（不动加水路）

```
1. A 开 · B 关 · 泵开 → 主箱供水         出水连续
2. A 关 · B 开 · 泵开 → 副箱供水         出水连续，主箱水位不动
3. A/B 都关 · 泵开 → 干转保护（若已实现）15 秒内断电
4. 边灌边用：中门接软管 + W1 开 + A 关 + B 开
   → 主箱水位上升的同时，全车由副箱供水  两路互不干扰
```

## 阶段 5 · 热水支路（小厨宝 + 阀D 夏季旁路，必装同期）

> 设计原理见 [design.md §热水子系统](design.md#热水子系统-米家小厨宝-s1)。**小厨宝不接混水阀**，靠自身温控；调温分层：水槽自带龙头、淋浴独立恒温阀。

### 5.1 安装小厨宝

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 小厨宝置于**近水槽柜内**（缩短热水管路） | 四周留散热空间，**不封死在密闭腔** |
| 2 | 确认供电：2000W 由 220V 逆变器供电 | **先核算逆变器余量**，见 [04-power-system](../04-power-system/) |
| 3 | 冷水进 → 阀 H → 小厨宝进水口 | 阀 H 装在小厨宝**上游且手可及处** |
| 4 | 小厨宝出水口 → **止回阀** → 阀 O → 热水主管 | **止回阀箭头指向用水点**（防倒灌） |
| 5 | **装泄压阀**，排水口接软管**引至车外或灰水箱** | 排水畅通，**绝不可堵死** |
| 6 | 热水管做保温包裹 | 减少管路热损 |

> ⚠️ **泄压阀排水绝不可堵死**——储水式加热时罐内膨胀，堵死会导致内胆超压。

### 5.2 贴阀门标签（热水侧三个阀 H / O / D）

**热水侧有阀 H、阀 O、阀 D 三个球阀**，缺一不可（阀D见 5.3.1）。

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 阀 H 贴「**H = 热水进水**」 | 标签清晰，暗处可辨 |
| 2 | 阀 O 贴「**O = 热水出水**」 | 同上 |
| 3 | 阀 D 贴「**D = 夏季旁路**」 | 同上 |

> ⚠️ **阀 D 是必装件，不是可选项**——理由见 5.3.1。早期方案曾判定"绕经热水主干的旁通是重复路径"而删除，**后来实测发现恒温阀不支持单边进水、且水槽热水口会断水**，该结论已推翻。
>
> **已删除的件不要再加回**：阀 C（被阀 D 取代）、阀 C 配套 DM 三通 ×2、小厨宝出水侧止回阀。理由见 [design.md §已删除的件](design.md#曾经设计过、现已删除的件-留档-避免重复入坑)。

### 5.3 装淋浴恒温混水阀

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 恒温阀**冷入口① ← 冷水母管（主干）**取一路 | **冷热不能接反**（接反会导致恒温阀失效） |
| 2 | 恒温阀**热入口② ← 热水母管（阀 O 之后）**取一路 | 两条管路均从母管**独立取**，不串接 |
| 3 | 恒温阀出口 → 花洒软管 | 见 [09-shower-module](../09-shower-module/) |
| 4 | 将恒温阀本体固定在淋浴区可触及处 | 不与浴帘干涉 |

> **为什么淋浴用恒温阀而不是手动混水阀**：恒温阀蜡感温包自带**流量补偿**，房车泵启停、多用水点开关引起的冷水压力波动它能自动修正；手动混水阀在固定开度下混合比会立刻跑偏。

#### 5.3.1 装阀 D（夏季旁路 · **必装 · 与热水支路同期做**）

> ★★ **必须在做热水支路这一期就装上，不能留到以后。** 理由见下方"不装的后果"。

**接法：直接在「进小厨宝的那条冷水管」上开三通 → 阀D → 就近接回热水主干（阀O 之后）。**

```
冷水主干 ─┬─→ [H阀] → 小厨宝 → [O阀] → 热水主干
          │                              ↑
          └──────[三通]──→ 球D ──────────┘（从冷水管旁路，不走下方绕圈）
```

**★ 核心：阀D 的取水点就在这条冷水管上，不需要从冷水主干末端另拉一根。** 冷水管本来就从主干下来直通 H 阀，在这条管上开个三通引出一路接阀D，最短最省。

| 接法 | 评价 |
|---|---|
| ❌ 冷水主干**末端**取水 + 热水主干**末端**灌回 | 绕全车一大圈；末端水压最低、阀D 出水量小；管阻大 |
| ❌ 冷水管先绕到下方再爬回来 | 白绕一圈，管长、压损、压占柜内空间 |
| ✅ **冷水管上直接开三通 → 阀D → 就近接阀O之后** | 取水就在冷水管上（**水压充足**）；环路最短；热水主干顺流向供水 |

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 在**进 H 阀的冷水管**上装 **三通**（位置尽量靠近 H 阀，管子不绕下方） | 快接锁止到位 |
| 2 | 三通引出一路接 **球 D** → 短距离接到**热水主干、紧贴球O 之后** | **环路尽量短**，禁止绕到主线末端再折回 |
| 3 | 球 O 之后立即装**汇入三通** | 三通紧挨阀O，不留长段死水 |
| 4 | 球 D 贴「**D = 夏季旁路**」标签 | 清晰可辨 |

##### 不装阀 D 会怎样（必读）

夏季关掉阀 H / 阀 O（不用热水）后，**热水主干整段断水**，于是：

| 受影响点 | 后果 |
|---|---|
| **水槽热水口** | **没水** → 水槽只剩单冷水口出水，等于半个水槽报废 |
| **恒温阀热入口** | 没水 → 实测已确认**恒温阀不支持单边进水**，淋浴出水量骤减甚至不出水 |
| 车尾热水预留 | 没水（将来装尾门恒温阀时同样废掉） |

**装了阀 D**，夏季把冷水灌进热水主干，上述三处**全部恢复有水**（出的是冷水），一处解决全车。

##### 为什么必须接热水主干、而不是接花洒

- **接热水主干** → 夏季热水主干里流的是冷水 → **水槽热水口、恒温阀热入口、车尾预留全都有水** ✅
- **只接花洒** → 只够救淋浴，水槽热水口照样没水；车尾装阀时还得再做一次

> **阀 D 与已删除的阀 C 的区别**：阀 C 接的是"冷水主干 → 热水主干"这条路径本身（当时判定重复而删）；**现在因实测不支持单边进水、且水槽热水口会断水，这条路径是必需的**——所以阀 D 回来了，位置就在阀C 原本的位置。
>
> **教训记录**：删阀 C 时未验证"关掉厨宝后各用水点在不在环上"就下了结论。**以后凡涉及"某条路径是否重复"的判断，应先验证关断状态下的流量可行性再决定删除。**

### 5.4 冷/热母管分接各用水点（★ 不得串接）

**原则：每个用水点从母管独立取一路，各装一个 DM 三通。严禁把某点挂在他点下游。**

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | **冷水主干**依次分出：水槽冷水口 → **车外取水口（中门）** → 淋浴恒温阀冷入口 → 车尾 | 每点一个 DM 三通，独立取路 |
| 2 | **热水母管**依次分出：水槽热水口 → 淋浴恒温阀热入口② → 车尾预留（封堵） | 同上 |
| 3 | **车外取水口只接冷水**（洗车/冲脚/涮锅），不接热水 | 明确不做混水，少一个阀少两个漏点 |
| 4 | 母管末端做**车尾预留**（见 5.4.1） | 封堵到位，不漏 |

> ⚠️ **串接是水路大忌**：若把外置取水挂在水槽下游，开水槽时外置水压骤降、水温也会被你水槽的冷水混合影响。**必须每点独立从母管取。**

#### 5.4.0 车外取水口（中门 · 洗车用）

**车外已装带自锁快接头，但内部尚未接管**。本次接法：**走泵单模式 + 单向阀**。

```
冷水主干 ━┳━[三通]━[球阀]━[单向阀]━→ 车外快接头（已装）
```

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | 冷水主干装 **DM 三通**，分出一路 | 快接锁止到位 |
| 2 | 接 **球阀**（平时关闭） | 手可及、标签清晰 |
| 3 | 接 **单向阀**，**箭头朝车外** | ★ 方向必须朝外（允许车内水出去、阻外部水进来） |
| 4 | 接到**已装的车外快接头** | 锁止可靠、不漏 |
| 5 | 贴标签「**车外取水 · 洗车**」 | 清晰可辨 |

> ⚠️ **单向阀方向装反 = 车外放不出水**（且极难排查）。装前用手指从车外往里吹气验证：**吹不进 = 方向正确**。
>
> ⚠️ **平时关闭球阀** —— 防止行车时车外口受压/受污。

#### 5.4.1 车尾热水预留（★ 现在铺管，不装阀）

**现状**：车尾现有 DM 管只到冷水快拆头（冲脚/冲车）。**车外洗澡帐篷未接，本期不装恒温阀。**

**但管路必须先铺** —— 趁柜体未做满一次做完，否则将来拆柜返工。

| 步骤 | 操作 | 验收点 |
|------|------|--------|
| 1 | **热水母管（阀 O 之后）** 加一个 **DM 三通** | 快接锁止到位 |
| 2 | 从三通铺 **DM 管至车尾柜** | 转角全用 DM 90° 弯头，无硬弯 |
| 3 | 车尾端装 **DM 封堵头封死** | 拧紧，打压不漏 |
| 4 | **管内不进水**（封堵即空气管） | 避免长期存水变质发臭 |
| 5 | 预留端留在**车尾柜内可见处**，贴标签「热水预留·勿拆」 | 两年后能找到 |
| 6 | 封堵头**不要打胶**，手拧紧即可 | 将来好拆 |
| 7 | 车尾柜内预留 **约 150×150 mm 空位** | 空位不被封死、不被做满 |
| 8 | 热水预留管**做保温**（同冷水管） | 接头密封圈不因冷热老化 |

> **冷水侧无需新增**——现有车尾冷水管将来直接进恒温阀冷水口。

**将来装阀时的做法**（留档，本期不做）：

```
1. 拆下热水预留封堵头 → 接恒温阀热水口
2. 现有车尾冷水管 → 接恒温阀冷水口
3. 把现有冷水快拆头从原管端挪到恒温阀出口
   → 车尾仍是「一个花洒口」，冲脚/冲车/洗澡共用
```

> ⚠️ **车尾只有一个出水口**——不设两个出水点。冲脚和洗澡共用同一个花洒。

### 5.4.2 车内恒温阀验证（★ 决定车尾是否装第二个）

**车内恒温阀已采购**。装好后按下表实测，**结果决定车尾要不要照买第二个**。

#### 测试一：单边进水测试 —— ✅ 已完成，结果：**不支持**

**实测方法**：恒温阀冷入口接自来水、热入口空着，开冷水观察流量。

**实测结果：出水明显偏小／不出水 → 该阀不支持单边进水。**

**结论：旁通阀 D 从"可选"变为"必装"。**

| 季节 | 球 H / 球 O | 球 D | 结果 |
|------|-------------|------|------|
| 正常（用小厨宝） | 开 / 开 | **关** | 厨宝供热水，三处热水点正常 |
| 夏季（拆厨宝） | **关 / 关** | **开** | 冷水灌入热水主干 → **全车热水点都有冷水** |

> ⚠️ **不要指望"让热水管流冷水"过关**：夏季拆厨宝后热水母管里确实是冷水，但那只是从**热入口**进水，同属单边进水场景，一样不行。

#### 测试二：热水性能验证（装好后实测）

| 验证项 | 怎么测 | 通过标准 |
|--------|--------|----------|
| **水量衰减** | 连续淋浴 3~5 分钟 | 全程维持目标温度，无由烫转凉 |
| **压力扰动** | 洗浴中开/关水槽冷水 | 恒温阀自动补偿，温度基本不漂 |
| **小厨宝跟得上吗** | 连续用水后观察小厨宝反复启停 | 无长时间「出冷水」段 |
| **关水再开** | 关龙头再开 | 温差可接受，无先烫后凉 |

**结果处理**：

- **阀 D 必装**（测试一已确认不支持单边进水；且不装会让水槽热水口断水）——见 5.3.1 安装步骤，**与热水支路同期完成**
- **测试二 4 项全过** → 车尾照买第二个恒温阀，按 5.4.1 预留直接装
- **测试二有不通过项** → 车尾改**手动混水阀**（40~90 元），或考虑加大热水容量

> **为什么必须实测**：7L 小厨宝配恒温阀的真实表现**无法预先判断**——可能很稳，也可能因容量太小而剧烈震荡。先花一个阀的钱验证，比直接买两个赌，理性得多。

### 5.5 热水调试与验收

```
1. 小厨宝注水（确认罐内满水）→ 再通电 ★ 空罐通电必烧加热管
2. 设定温度，等待加热完成
3. 开水槽热水：出水温度稳定、无忽冷忽热
4. 开淋浴恒温阀：调至目标温度，观察是否稳定
5. 压力波动测试★：同时开关另一个冷水点（如水槽/外置取水），观察淋浴出水温度
   → 恒温阀应自动补偿，温度基本不漂移
   → 若温度明显漂移，检查是否有人把某点串接在他点下游
6. 车尾预留封堵头打压检漏：确认不漏
7. 检查泄压阀排水管：加热时若有滴排水，应顺畅流入车外/灰水箱
```

> ★ **第 5 步是本方案的核心验收项**——它直接验证了"为什么淋浴必须用恒温阀"。

### 5.6 夏季拆除 / 冬季排空 SOP（打印塑封贴柜内）

**夏季长期不用热水**
```
1. 断小厨宝电源
2. 先开泄压阀泄压 → 再关阀 H
3. 关阀 O
4. 淋浴洗冷水：直接用恒温阀「冷入口①」（主干直供）★ 单边供水需先实测
5. 若要整机拆除：断电 → 泄压 → 排空罐内 7L 水 → 关阀 H/O → 拆管拆机
```

## 施工红线（违反必返工）

1. **泵运转中切换阀门** — 会导致两路同吸或全关干转
2. **用剪刀切 4 分管** — 切口压扁，必漏
3. **快接漏水后"再往里捅一点"** — 必须重切管口再插
4. **桶盖完全密封** — 桶会被吸扁，必须留通气孔
5. **吸水侧不装粗滤** — 一颗砂粒卡死隔膜泵阀片
6. **单向阀装反** — 完全不出水，且极难排查
7. **泵在管未固定前通电** — 管子甩动脱接头
8. **用电磁阀做吸水侧自动切换** — 失去物理冗余，逻辑出错即烧泵
9. **小厨宝接混水阀** — 储水式靠自身温控，接混水阀必然忽冷忽热（详见 [design.md §热水子系统](design.md#热水子系统-米家小厨宝-s1)）
10. **小厨宝空罐通电** — 必烧加热管，必须先注满水
11. **堵死泄压阀排水口** — 储水式加热膨胀会导致内胆超压
12. **带压拆热水管** — 先断电 → 泄压 → 再拆管
13. **淋浴恒温阀冷热接反** — 恒温功能失效
14. **擅自加回阀 C 旁通** — 重复路径，恒温阀冷入口已直连主干，白占空间
15. **用水点串接**（把某点挂在他点下游）— 他点一开水压水温就变，且极难排查
16. **车尾不铺热水预留管** — 将来加装车外淋浴要拆柜板重新走管
17. **车尾预留管封堵头打胶** — 将来拆不开，预留作废（手拧紧即可）
18. **车外取水口误接热水或做混水** — 洗车冲脚不需要调温，徒增阀门与漏点
19. **车外取水口单向阀装反** — 车外放不出水，且极难排查
20. **用车上口给洗车机供水时不开泵** — 洗车机自吸抽负压，可能吸开泵止回阀、吸扁水桶
21. **在车上管路里抽浑水** — 泥沙卡死隔膜泵阀片
19. **恒温阀只接单边进水而不实测** — 部分型号单边供水出水极小甚至不出水，夏季拆厨宝后淋浴废掉
20. **靠「热水管流冷水」过夏季** — 那仍是单边进水场景，不可靠（见 design.md 重要纠正）

## 新增红线（车尾副箱 · 双加水口，2026-10）

> 完整理由见 [design-tank-portability.md §12](design-tank-portability.md#12-红线新增追加到-build-guide)。编号接上文。

22. **加水口只装普通单向阀、不装回吸切断阀** — 满水行车 / 两注口互串必溢
23. **两个注口中只装一个切断阀** — 一箱灌满，水从另一个口冒出来
24. **W1 与 W2 同时开** — 主副箱连通，水位互拉、容易溢
25. **拔副箱前不关 C** — 自封与底阀是备份，不是替代品
26. **补给路不装 CV2** — 主箱水倒灌回副箱
27. **副箱限位全靠摩擦力** — 不做"只能向外取出"的限位，行车会滑出
28. **注口低于箱体最高水面** — 回吸切断阀失效、重力倒灌
29. **为"自动补给"去改已装好的泵吸入侧** — 收益远小于返工风险（先走退路 A 手动插管）
30. **中门注口与车外洗车口共用同一管口** — 两个方向互相污染
31. **在副箱上走固定接线做水位检测** — 箱子要能走，传感器必须无线（BLE/电池型）
