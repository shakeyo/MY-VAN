## 核心理念

### 可拆检 · 年审友好

全部体块通过角码 + 螺栓压紧地台预埋点。进出水快接、电路插头化、模块独立拆卸。年审时松螺栓、断快接，恢复空车。

### 先外后内 · 先结构后装饰

施工严格按序：底盘 → 车顶 → 外观 → 管线预埋 → 木工 → 软装 → 淋浴 → 智控 → 影音。每阶段不反复、不返工。

### 文档即施工标准

每个模块含设计决策 (design.md)、施工指南 (build-guide.md)、材料清单 (bom.md)。图文对照、参数明确、可直接按文档施工。
