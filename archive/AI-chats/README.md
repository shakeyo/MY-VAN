# AI 对话归档区

本目录存放与 AI 的原始对话记录，作为方案提炼的原材料。

## 存放规则

直接丢 `.md` 文件进来，命名格式：

```
YYYY-MM-DD-主题关键词.md
```

例如：
- `2025-07-24-控制面板布局调整.md`
- `2025-07-24-485继电器接线确认.md`

## 整理工作流

当你说"整理到模块"时，我会：

1. 读取本目录下未标记的文件
2. 提取有价值的内容（方案决策、尺寸、BOM、施工要点）
3. 更新对应模块的 `design.md`、`build-guide.md`、`bom.md`
4. 已整理的文件重命名为 `YYYY-MM-DD-主题--已整理.md`

## 注意

- 原始对话只作为归档，不直接引用
- 所有可落地的内容必须沉淀到 `modules/` 下的正式文档
