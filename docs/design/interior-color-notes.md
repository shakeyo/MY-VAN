# 内饰配色与材质笔记

## 地板与柜体配色

### 白色木蜡油柜体
- 这款地板颜色比较"跳"，有灰、有黄、有深褐。如果立面（柜子）也是复杂的木纹，空间就没有了视觉重心。
- 白色木蜡油的柜体就像一张白纸，能把地板这种"动"的感觉压下来，让空间安静下来。
- 大面积的白色木蜡油（透着淡淡木纹的白）能瞬间提升空间的明亮度和洁净感，让复古风变成"现代极简复古风"。

### 台面与地板的搭配
- 台面颜色偏暖、偏橘的"黄橡木色"与实物地板的冷灰/沉稳褐色不协调
- 建议用"白桦木"或"白橡木"原色，只涂透明木蜡油
- 白桦木海洋板台面的颜色偏淡黄白，能完美衔接白色柜体和灰调地板
- 最终组合：浅木色台面（点缀）+ 白色木蜡油柜身（主调）+ 灰褐色复古地板（基础）

### 露边细节 (Exposed Edges)
- 海洋板要利用侧边纹理
- 柜门、侧板刷白色木蜡油，但侧边截面（层叠的木质线条）不刷白，只涂透明油或打磨光滑
- 地板的人字拼线条和柜体侧边的千层饼线条形成几何美感呼应

### 最终色彩配比
- 大面积立面（柜子/墙面）：白色木蜡油（海洋板擦白）
- 地面：花纹丰富，上面尽量简洁
- 台面：纹理清爽、颜色最浅的天然木色（白桦木），不加色
- 五金/骨架：黑色型材骨架保留，黑色线条勾勒白柜子轮廓

### 面板材质
- 毛毡+木板来做面板
