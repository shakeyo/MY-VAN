# VAN-PROJECT: Dependency Graph

此列表明确了项目各模块之间的依赖关系，帮助在施工过程中合理安排优先级。

## 🛠️ 硬件与底层依赖

### 1. 核心电力依赖
- **[副电瓶系统 (12V House)]** -> 供电给 -> **[N100 主机]**
- **[副电瓶系统 (12V House)]** -> 供电给 -> **[GL.iNet 路由器]**
- **[副电瓶系统 (12V House)]** -> 供电给 -> **[RS485 继电器模块]**
- **[副电瓶系统 (12V House)]** -> 供电给 -> **[安卓车机/平板]**
- **[副电瓶系统 (12V House)]** -> 供电给 -> **[卡座冰箱/USB]**

### 2. 网络基础设施依赖
- **[GL.iNet 路由器]** -> 提供局域网给 -> **[N100 (HA)]**
- **[GL.iNet 路由器]** -> 提供局域网给 -> **[安卓大屏 (Dashboard)]**
- **[GL.iNet 路由器]** -> 提供局域网给 -> **[ESP32 控制板]**

## 📶 传感器与执行器依赖

### 3. 数据采集链路
- **[485 库仑计/水表]** -> 物理接入 -> **[USB-to-485 转换器]** -> 接入 -> **[N100]**
- **[OBD-II 蓝牙版]** -> 蓝牙连接 -> **[安卓车机 (Torque)]** -> MQTT -> **[N100 (HA)]**

### 4. 视频监控链路
- **[AHD 摄像头]** -> 信号并联 -> **[DVR/编码器]** -> RTSP -> **[N100 (Frigate)]**
- **[N100 (Frigate)]** -> 处理画面 -> **[HA Dashboard]** -> 显示在 -> **[各终端屏幕]**

## 💻 软件逻辑依赖

### 5. 系统集成链路
- **[N100 (PVE/LXC)]** -> 运行 -> **[Home Assistant]**
- **[Home Assistant]** -> API/WebSocket -> **[rv-smart-dashboard]**
- **[Home Assistant]** -> 自动化逻辑 -> **[RS485 继电器]** -> 控制 -> **[全车灯光/水泵]**

---

## 📅 施工顺序建议 (Priority Order)

1.  **[网络与中枢]**: 优先部署副电瓶常电供电及路由器、N100 环境。
2.  **[底层控制]**: 部署 RS485 总线与继电器模块，实现物理开关与 HA 同步。
3.  **[工程结构]**: 搭建铝型材框架，预埋水电管线。
4.  **[终端显示]**: 安装生活区安卓大屏，调试 rv-smart-dashboard。
5.  **[视觉与音响]**: 最后进行监控调试与 DSP 声场调音。
